# dashboard/CLAUDE.md — 오너용 화면 작업 규칙 (이 폴더 파일을 열 때만 자동 로드됨)

- 오너는 폰으로 본다. 게시 전 스킬 `dashboard-qa` 합격선(글씨 ≥14/16px, 대비 ≥4.5:1, 가로 스크롤 0, 긴 작업 0, 콘솔 에러 0)을 **측정값으로** 통과해야 한다.
- 태스크 데이터는 `TASKS.md` → `node tools/sync-dashboard.mjs` 로만 갱신(손으로 status.json 태스크 수정 금지).
- 끌기·확대 캔버스 같은 직접 제스처 금지(렉·흐림). 브라우저 기본 스크롤 사용. 같은 창 탭 이동 유지, 페이지 합치지 않기(오너 지시).
- 색은 차사 팔레트(아트팀 소유)만. 화면 구현 후 아트팀 검수 → 통과 후 오너 보고.
