# 차사 (Chasa) — 단계 0 프로토타입

> **목표는 단 하나: 그림 없이, 도형만으로 "때리는 손맛"이 재밌는지 확인한다.**
> 에셋(그림/소리/모델)은 일절 없고, 전부 색깔 도형입니다.

기술: Vite + TypeScript + Three.js

---

## 실행 방법 (처음 한 번만 하면 되는 준비 포함)

### 0. 준비물
- **Node.js** 설치 (https://nodejs.org 에서 LTS 버전). 설치 후 터미널에서 `node -v` 를 쳐서 숫자가 나오면 성공입니다.

### 1. 부품 설치 (처음 한 번만)
```bash
npm install
```
> `npm install` = 이 게임이 쓰는 외부 부품(Three.js 등)을 내려받는 명령입니다.

### 2. 게임 실행
```bash
npm run dev
```
터미널에 `http://localhost:5173/` 같은 주소가 나옵니다. 그 주소를 브라우저(크롬 권장)에 붙여넣으면 바로 플레이됩니다.
**코드나 숫자를 고치고 저장하면 브라우저가 자동으로 새로고침됩니다.**

### 3. 배포용 빌드 검사 (선택)
```bash
npm run build
```
에러 없이 끝나면 정상입니다. 결과물은 `dist/` 폴더에 생깁니다.

## 조작법

| 입력 | 동작 |
|---|---|
| **좌클릭 (바닥)** | 그 지점으로 이동 (누른 채로 끌면 마우스를 따라 걸음) |
| **좌클릭 (적)** | 철삭 3타 콤보. 멀면 먼저 달려가서 때림 |
| **좌클릭 연타** | 1타 → 2타 → 3타(한 바퀴 회전)로 이어짐. 후딜 중에 미리 눌러둬도 됨 |
| **우클릭** | 견인: 커서 근처의 적을 사슬로 낚아 내 앞까지 끌어당김 |

**추천 테스트 순서:** 적들이 모일 때까지 기다림 → 좌클릭 3연타(주변 적이 한꺼번에 맞고 날아가는지) → 멀리 있는 적에게 우클릭(끌려오는지) → 끌려온 직후 좌클릭 콤보(멍한 틈에 때려 넣는 맛).

## 타격감 5요소 (이 단계의 전부)

| 요소 | 어디서 | 설명 |
|---|---|---|
| 히트스톱 | `effects.ts` `HitFeel` | 맞는 순간 게임 세계가 2~4프레임 얼어붙음 |
| 화면 흔들림 | `effects.ts` `HitFeel` + `stage.ts` | 타격 세기에 비례해 카메라가 떨림. **멈춘 동안에도 떨림** |
| 넉백 | `enemy.ts` `takeHit` | 맞은 적이 사슬에 쓸려 날아가고 마찰로 멈춤 |
| 데미지 숫자 | `effects.ts` `DamageNumbers` | 크게 튀어나왔다가 포물선으로 떨어지며 사라짐 |
| 사슬 궤적 잔상 | `chain.ts` `SwingTrail` | 휘두른 자리에 빛나는 띠가 남았다가 사라짐 |

## 숫자 조절하기 (가장 중요)

**모든 "감으로 잡은 숫자"는 `src/config.ts` 한 파일에 모여 있습니다.**
숫자를 바꾸고 저장 → 브라우저에서 바로 확인, 이 반복으로 손맛을 만드세요.

자주 만지게 될 값:

| 이렇게 느껴지면 | 이 값을 |
|---|---|
| 때릴 때 "툭툭" 가볍다 | `COMBO[n].hitStopFrames` ↑, `knockback` ↑, `shake` ↑ |
| 멈칫하는 게 답답하다 | `hitStopFrames` ↓ (2 → 1) |
| 화면이 너무 어지럽게 흔들린다 | `FEEL.SHAKE_MAX_OFFSET` ↓ |
| 적이 너무 멀리/가까이 날아간다 | `COMBO[n].knockback` 또는 `ENEMY.KNOCKBACK_FRICTION` |
| 휘두르는 게 느리다/굼뜨다 | `COMBO[n].windup`, `swing`, `recover` 시간 ↓ |
| 한 번 휘두를 때 맞는 범위가 좁다 | `COMBO[n].reach`(사거리), `sweepDeg`(각도) ↑ |
| 잔상이 너무 오래/짧게 남는다 | `TRAIL.LIFETIME` |
| 적이 너무 빨리/천천히 온다 | `ENEMY.SPEED` |
| 적 수를 바꾸고 싶다 | `ENEMY.COUNT` (3~5 권장) |
| 화면이 너무 멀다/가깝다 | `CAMERA.VIEW_HEIGHT` |

## 폴더 구조

```
src/
  config.ts   ← 숫자 조절판 (여기만 만지면 됨)
  main.ts     ← 시작점 + 게임 루프 (히트스톱 시간 처리)
  stage.ts    ← 렌더러/쿼터뷰 카메라/조명/바닥
  player.ts   ← 이동, 3타 콤보, 견인 (상태 머신)
  enemy.ts    ← 적 + 적 무리 관리
  chain.ts    ← 사슬 모양 + 궤적 잔상
  effects.ts  ← 히트스톱, 화면 흔들림, 데미지 숫자, 클릭 표시
  input.ts    ← 마우스 입력 → 3D 월드 좌표 변환
  util.ts     ← 작은 수학 도구
```

## 의도적으로 만들지 않은 것
적의 복잡한 AI(공격/회피), UI, 메뉴, 사운드, 텍스처, 모델링. 이 단계에서는 "때리는 손맛"만 봅니다.
