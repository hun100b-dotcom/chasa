# art-prompt-gate — 비주얼 생성 관문 (아트팀)

> 왜 필요한가: AI 생성물은 프롬프트가 곧 "무엇을 참고했는가"의 기록이다. 작품명이 한 번이라도 들어가면 방어가 불가능하다.
> 또 채팅에서 이미지를 글로 왕복하면 토큰만 새므로, 플랫폼에서 뽑아 **파일로** 들이는 게 룰 3이다.

## 프롬프트 작성 전 (체크 5)
1. 작품명·작가명·게임명·캐릭터명 **0개**. 대신 사조·재질·조명 언어로 직접 지시
   (예: "저채도 남청색 환경광, 습한 석조 질감, 낮은 키 라이팅, 안개층").
2. 색은 `docs/art/palette-tokens.json` 의 HEX로 **직접** 명시(토큰 이름만 쓰지 말고 값까지).
3. 주인공 실루엣 고정 요소 5개를 항상 포함: 흑립 / 검은 도포 / 붉은 띠 / 철삭 / 혼불. 낫·해골 얼굴·기모노·후드 로브는 **네거티브**에 넣는다(일본 사신과 혼동 방지).
4. 한 번에 **변수 1개**만 바꿔 재생성한다(일관성 유지, 원인 추적 가능).
5. 캐릭터는 첫 승인 이미지를 **레퍼런스 시트**로 고정하고 이후 생성에 그 파일을 첨부한다(플랫폼의 캐릭터 고정 기능이 있으면 사용).

## 실행
- 프롬프트 텍스트를 먼저 파일에 저장 → `node tools/ip-scan.mjs <프롬프트 파일>` 통과 → 생성.
- 생성 결과: `assets/raw/`(대용량, git 제외) 또는 `assets/work/`(경량, git 포함). 폴더 `README.md`에 **프롬프트·날짜·모델·시드** 기록.
- 채팅 보고는 이미지(파일)로. 글로 외모를 길게 설명하지 않는다.

## Higgsfield 메모 (조사 2026-10-24)
- 공식 MCP 서버 주소 `https://mcp.higgsfield.ai/mcp`, 이미지·영상 30+ 모델, 별도 API 키 불필요(로그인 방식 연결).
- 클로드 커넥터 디렉터리에는 아직 없음 → 계정·크레딧(구독) 준비와 커넥터 연결이 필요한 **오너 계정 작업**이라,
  비주얼 생성 착수 시점에 코디네이터가 한 번에 안내한다(현재는 플랫폼에서 직접 뽑아 파일로 마운트하는 기존 절차 유지).
- 요금·크레딧 소모량은 공식 페이지에서 확인되지 않음 → 사용 전 단가 확인 필요.

## 거부권
금지 항목이 들어간 요청은 누가 시켰든 거부하고 대체 문장을 제안한다.
