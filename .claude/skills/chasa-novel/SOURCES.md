> 가져온 것은 **기법(어떻게 쓰는가)뿐**이다. 문장·인물·설정·장면은 하나도 가져오지 않았다. 아래 작품들은 금지 IP 목록(`docs/IP-SAFETY.md`)과 겹치지 않는다.

## 1. 작품과 뽑은 기법

| 작품 | 뽑은 기법 | SKILL.md |
|---|---|---|
| 한강 『소년이 온다』·『작별하지 않는다』 | 죽은 이의 시점, 다중 화자, 남은 자가 기억해야 할 책무를 서사로 만들기, 기억을 위한 과정 자체를 이야기로 | §15 남는 자의 책무, 죽은 이들의 합창 |
| 황석영 『손님』 | 굿(진지노귀굿 열두 마당)을 소설의 얼개로 삼기, 산 자와 죽은 자가 겹쳤다 떨어지며 과거를 현재로 불러오기, 해원 | §15 의례로 짠 구성, 산 자와 죽은 자의 겹침 |
| 후안 룰포 『페드로 파라모』 | 조각난 구성, 소리가 기억(웅얼거림), 한순간은 길게 수십 년은 한 문장(시간 배율), 누가 죽었는지 늦게 드러내기 | §15 소리가 기억의 문, 시간 배율 |
| 조지 손더스 『바르도의 링컨』 | 죽은 이들의 합창(같은 사건을 여러 각도로), 중심 인물의 목소리를 아끼기, 슬픔을 차가움·문간 같은 몸의 이미지로 | §15 죽은 이들의 합창, §3 감정 이름 금지 |
| 가즈오 이시구로 『파묻힌 거인』 | 망각과 안개, 고르지 않게 떠오르는 기억, 큰 주제 앞의 담담한 어조 | §15 절제의 어조 |
| 어슐러 K. 르 귄 『머나먼 바닷가』(어스시) | 참이름의 힘, 이름을 버린 자의 끝없음, 죽음 너머를 다 보여 주지 않는 절제, 적의 정체를 늦게 발견 | §15 이름의 힘, §10 미스터리 규율 |
| 위화 『인생』 | 반복되는 죽음 앞의 절제("그저 죽음을 확인할 뿐"), 일상의 시선 | §15 절제의 어조, §8 장례 |
| 헤밍웨이 빙산 이론 | 생략의 원칙: 알고 빼면 강해지고 모르고 빼면 구멍. 표면은 참된 구체로 | §15 빙산, §2 큰물 밤 |
| 제임스 우드 『소설은 어떻게 작동하는가』 | 자유간접화법(꼬리표 없이 인물의 말맛이 서술에 섞임) | §2 |
| 드와이트 스웨인의 장면과 후속 | 목표-맞섬-결과 / 반응-딜레마-결정, 장면마다 무언가 바뀌어야 함 | §5-2 |
| 프롬소프트웨어식 환경 서사(게임 글쓰기) | 사건이 아니라 뒤끝, 짧은 조각이 질문을 남기기, 조각끼리 서로를 설명하기 | §15 사건이 아니라 뒤끝, 장소가 기억한다 |
| 토니 모리슨 『빌러비드』 | 조각난 목소리, 소리, 되풀이(트라우마의 원) — 초록만 확인 | §5-3 (참고만) |

조사했으나 기법 근거가 약해 쓰지 않은 것: 윤흥길 『장마』(기사에 시점·결말 분석 없음, 사투리·빗줄기 묘사 평만 확인), 이청준 『축제』(열어 본 기사에 해당 내용 없음), 김동리 『무녀도』(줄거리만 확인), 미야자와 겐지 『은하철도의 밤』(여정 틀만 확인), 이영도 『눈물을 마시는 새』(평가 기사뿐).
