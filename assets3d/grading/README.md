# 화면 분위기 권장값 — 색보정표(LUT)·블룸·비네트·천도 시야 축소 (아트 → 코드팀)

기준: 아트 디렉션 **고딕 호러 + 단청 원색**. 어둠은 순검정이 아니라 남청(#0F1729·#16213E), 화면 대부분은 낮은 채도, 색은 *의미*에만 살린다(붉음=차사·위험, 금=단청·장비, 청록=천도, 보라=원념·기억). 풀빛·황록은 일부러 죽인다. **주황은 파혼 전용이라 화면 전체 틴트로 쓰지 않는다.**
전후 비교는 갤러리 s43~s45. 값 원본: `assets3d/grading/grading_params.json`, 만든 도구: `tools/art3d/grading.py`. 모든 수치는 렌더 사진(8비트)으로 잡은 **1차 권장값** — Unity 실제 화면에서 튜닝해 확정.

## 1. 색보정표(LUT) 22장 — assets3d/grading/
시간대 4 × 날씨 5 = 20장(`lut_<시간>_<날씨>.png`, 시간 dawn/day/dusk/night · 날씨 clear/cloudy/rain/fog/plague) + `lut_neutral.png`(아무것도 안 바꿈, 점검용) + `lut_tendo.png`(천도 중).
- 형식: 1024×32 가로 띠(32³). 가져오기 설정: **sRGB 끔, 압축 None, Mip 끔, Wrap Clamp, Filter Bilinear**. 칸=파랑, 칸 안 가로=빨강, 그림 위쪽=초록 큰 값. `lut_neutral.png` 를 먼저 걸어 화면이 안 변하는지 확인하면 방향이 맞는지 안다.
- URP: Volume → Color Lookup(Texture=띠, Contribution=1.0). 두 LUT를 섞으려면 Volume 두 개를 가중치로 섞거나(권장), 스크립트에서 두 띠를 Lerp 한 임시 텍스처를 쓴다.
- 어느 LUT인지: `hour_map` — 새벽 4.5~7.0 / 낮 7.0~16.0 / 저녁놀 16.0~19.5 / 밤 19.5~28.5(=다음 날 4.5). 경계 앞뒤 0.5게임시간(약 50초)은 smoothstep 으로 두 LUT 교차. 시각은 `ClockSky`가 쓰는 `SkyKeys.HourOf`와 같은 기준.
- 날씨: `WeatherState` 의 구역별 날씨 키(Clear/Cloudy/Rain/Fog/Plague)로 LUT 날씨 칸을 고르고, 바뀔 때 1.5초 교차. 보스 곁은 보스 날씨 고정이므로 같은 규칙으로 따라간다.

시간대 기본(맑음) 보정값(참고용 — LUT 안에 이미 구워짐. 코드가 직접 계산하지 않아도 됨):
| 시간대 | 노출 | 대비 | 채도 | 검정 띄움 | 단청 원색 강화 | 풀빛 죽임 |
|---|---|---|---|---|---|---|
| 새벽 | 0.02 | 1.1 | 0.68 | 0.08 | 0.4 | 0.6 |
| 낮 | -0.04 | 1.14 | 0.78 | 0.025 | 0.42 | 0.65 |
| 저녁놀 | -0.1 | 1.18 | 0.88 | 0.03 | 0.45 | 0.65 |
| 밤 | -0.06 | 1.24 | 0.74 | 0.035 | 0.6 | 0.7 |
날씨는 그 위에: 흐림(채도 ×0.86·약간 어둡게) / 비(채도 ×0.72·청회색·검정 띄움) / 안개(채도 ×0.62·대비 ×0.8·검정을 안개색으로 크게 띄움) / 역병(채도 ×0.68·그늘과 중간톤이 병든 청록, 붉은색은 오히려 강화 — 핏빛 대비).

## 3. 천도 시야 축소 연출 (시전 중) — `grading_params.json` 의 `tendo`
요구사항 원본: docs/art/VISION-SHRINK-STUDY.md. 아래는 그 요구를 값으로 옮긴 것.
| 항목 | 값 |
|---|---|
| 반경 | 평소 끔 → **0.6**(단위: 화면 대각선의 절반=1.0). 작은 화면 하한 0.55. 조일 때 0.25초 `easeOutCubic`, 풀릴 때 0.15초 `easeInQuad`(들어갈 땐 조이고 나올 땐 빨리 풀려 해방감) |
| 가장자리 색 | 순검정이 아니라 **남청 #0F1729**, 바깥 불투명도 0.94 → 안쪽 0 |
| 가장자리 모양 | 부드러운 비네트 대신 **먹 번지는 경계**: 경계 두께 = 반경의 12%, `vision_noise.png`(이음매 없는 잡음)로 경계를 ±0.07 흔들고 UV를 천천히 흘림(0.012, -0.008)/초 |
| 단청 문양 | `vision_pattern.png`(1024×96, 가로로 한 바퀴 이어짐: 금 마름모·붉은 속 마름모·청록 점·연꽃잎 + 금/적/청록 세 줄). 가장자리 띠에 **불투명 14%**(#D4A94E 색조). **보스 천도는 한 겹 더 켜고 24%** |
| 중심 빛 | 차사와 대상 혼 두 곳에만 청록 #5FE3C0 글로우(반경 2.4m / 1.6m, 세기 0.55). 진행도는 글로우가 아니라 **대상 혼의 윤곽이 또렷해지는 정도**로 표현 |
| 색보정 | `lut_tendo.png`(채도 0.45·청록 하이라이트·남청 그늘)를 기본 LUT 위에 **0 → 0.6**으로 0.25초에 섞고, 끝나면 0.15초에 뺀다. 이 동안 기본 비네트는 0으로(겹치면 가장자리가 죽음), 블룸 세기 ×1.25·청록 틴트 |
| 위험 신호 | 시야 밖에서 다가오는 적의 *방향*만 가장자리에 **붉은 호 #E85C41**(폭 28°, 불투명 0.15~0.55 맥박, 2.5Hz — 3Hz 이하 규칙). 모습은 안 보인다 |
| 성공 순간 | 보라 **#C9B0FF** 테두리 18px, 0.3초 번쩍. **파혼에는 없음**(이야기 없음을 색으로 대비) |
셰이더 한 장(풀스크린) 의사 코드:
```
d  = length(uv - center) / (R * radius)            // R = 화면 대각선 절반
dd = d + (tex2D(noise, uv*1.0 + scroll).r - 0.5) * 0.14
a  = smoothstep(1-0.12, 1+0.12, dd) * 0.94          // 먹 번짐 가장자리
rgb = lerp(rgb, #0F1729, a)
ang = atan2(dy,dx)/(2π); pv = saturate((dd-(1-0.12*1.8))/(0.12*1.8))
pat = tex2D(pattern, float2(frac(ang*2), pv))        // 가로 2번 이어 붙임
rgb = lerp(rgb, pat.rgb, pat.a * (boss ? 0.24 : 0.14) * saturate((a-0.2)*4))
rgb += 위험 호(방향별) + 성공 테두리
```

## 4. 확인해 주세요
- 위 미리보기는 Blender 렌더(8비트)에 파이썬으로 같은 식을 적용한 것이라 **Unity의 블룸·톤매핑과 느낌이 다릅니다.** 블룸 문턱·세기는 Unity에서 밤 서낭당·천도 기둥을 보며 먼저 조정하세요.
- 안개·비 겉모습(안개 층·빗줄기)은 미리보기에서 흉내 낸 것이고 실제 효과는 코드팀 구현입니다. LUT는 색만 담당.
- 낮 LUT는 풀을 회청록으로 죽여 '고딕' 쪽으로 기울였습니다. 낮이 너무 칙칙하면 `day` 의 `sat`·`mute` 만 올리면 됩니다(`tools/art3d/grading.py` → `python3 grading.py luts`).
