# 보스 3종 예비동작(공격 예고 몸짓) — 코드 타이밍에 맞춤

원칙: 공격마다 **예비동작이 시작되는 프레임 = 0, 피해·바닥이 터지는 프레임 = 클립 끝(hit)**. 그래서 코드는 "예고 시작 때 클립 재생 → 끝 프레임에 판정"만 하면 몸짓과 판정이 어긋나지 않는다.
읽히는 순서(전부 같은 틀): ① 신호(0~0.15초: 숨 들이쉬기·몸 낮추기로 실루엣이 확 바뀜) ② 점점 커짐(방울 흔들림 가속·번호 부르기·삿대 젖힘) ③ 가득 찬 채 떨며 멈춤(마지막 6~12프레임, 이벤트 `loaded`/`flash`에 붉은 번쩍·소리) ④ 내리침(= 판정).

| 보스·공격 | 클립 | 길이 | 코드 값 | 판정 프레임 | 읽히는 몸짓 |
|---|---|---|---|---|---|
| 나루 영감 삿대 내리치기 | Windup | 33f(0.55초) | ENEMY_ATTACK_WINDUP 0.55 | 33 | 몸 낮춤 → 삿대 뒤로 크게 젖힘 → 부르르 → 휘두름 |
| 같은 기술, 첫 예고(×1.5) | WindupFirst | 50f(0.83초) | JudgeSystem 첫 예고 ×1.5 | 50 | 같은 모양을 천천히 |
| 나루 휘두른 뒤 | SwingRecover | 30f | — | — | Windup 끝 자세에서 이어 붙여 후딜 |
| 월화 열두 거리(잔 3개) | Open | 60f(1.0초) | B02_WARN_TIME 1.0 | 60 | 방울을 가슴에 모음 → 점점 빨라지는 방울 흔들기(이벤트 ring_bell) → 머리 위로 높이 들고 떨기 → 내리침 |
| 월화 2국면(잔 5개) | Open_P2 | 60f | 같음 | 60 | 같은 길이에 한 바퀴 돌며 올라감(더 크다는 신호) |
| 서 의원 번호 부르기 1파동 | Call | 48f(0.8초) | B03_WARN_TIME 0.8 | 48 | 몸 젖히고 손을 높이 들어 세 번 번호를 부르며(12·24·36f) 손이 좌→가운데→우로 칸을 짚음 → 떨며 멈춤 → 내리찍음 |
| 서 의원 2·3번째 파동 | CallNext | 48f | 같음 | 48 | 앞 파동 끝 자세에서 시작, 박자가 더 빠름(10·20·30f) |

사용법: 파동이 연속이면 Call → (찍은 자세 유지) → CallNext → CallNext. 간격(B03_WAVE_GAP 1.2초) 동안은 클립 끝 자세 유지 후 다음 파동 시작에 CallNext 재생.
기존 `Swing`(나루), `Whip`·`Stamp`(코드에 아직 안 쓰이는 보조 기술)은 그대로 있다. 옛 66f 예비동작은 `WindupLong`(연출용)으로 남겼다.
예비동작이 0.5초 이상 읽히는지: 나루 33f는 ①신호 4f + ②젖힘 12f + ③가득 찬 떨림 11f로 0.55초 안에 세 단계가 모두 보인다. 월화·서 의원은 0.8~1.0초.
주의: 보스 3D 모델 클립을 재생하는 코드 연결(예비동작 시작 때 클립 지정)은 아직 없어서(지금은 `boss_*_attack` 그림만 바뀜) 코드팀이 연결해야 보인다.
