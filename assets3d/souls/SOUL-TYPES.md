# 필드 혼 3유형 — 모델·동작·행동 규칙 제안 (아트 → 코드팀·기획)

혼 4등급(기획서 나이 이름: 갓 죽은/해 넘긴/오래된/덩어리, 파일 키 fresh/day/old/lump)은 **색·세기**, 유형은 **몸·행동**. 3유형 × 4등급 = 12 모델.
기획서에 혼 유형 규정이 없어 1막용으로 제안한다. 숫자는 balance.json 기본 적(공격 선딜 0.55s·피해 10·간격 2.6s·사거리 2.2·속도 2.8)을 1.0으로 둔 **임시 비율**.

| 유형 | 파일 | 역할 | 몸 |
|---|---|---|---|
| 넋두리 wail | assets3d/souls/soul_wail_<등급>.glb | 원거리 원념 투척 | 보통 키, 오른손에 보라(#B04FD0) 원념 구슬 |
| 잔넋 mote | soul_mote_<등급>.glb | 무리 | 0.5m 둥근 작은 혼, 눈만 |
| 묻힌 혼 buried | soul_buried_<등급>.glb | 매복 | 흙무덤 + 솟는 몸 |
원념 탄: assets3d/fx/fx_wonnyeom_orb.glb. (주황은 파혼 전용이라 안 씀.)

## 동작 클립 (60fps, 이벤트 프레임은 매니페스트 `assets3d/souls/_soul_types_manifest.json`)
- wail: Float 90f 루프 / Windup 42f(번쩍 28) / Attack 22f(투척 5, 탄=fx_wonnyeom_orb) / Kneel 40f
- mote: Float 40f(빠른 떨림) / Windup 18f(번쩍 14) / Attack 14f(적중 4) / Kneel 24f
- buried: Hidden 60f 루프(무덤만, 손끝 삐죽) / Windup 44f(번쩍 26, 솟구침 30, 먼지 26) / Attack 20f(적중 6) / Kneel 40f / Sink 30f(먼지 22)

## 행동 규칙 제안
**넋두리** — 거리 7~9m 유지(플레이어가 3m 안이면 뒷걸음, 느리게). 시야 안에서 선딜 0.7s(바닥에 원념 궤적 예고선) 후 투척. 탄 속도 9m/s, 피해 8, 간격 3.5s, 직선탄(회피 가능, 사슬로 쳐내면 소멸). HP 0.7배. 약점: 사슬 견인으로 끌어오면 무방비.
**잔넋** — 3~5마리 무리(대장 1마리를 천도하면 나머지 2초 혼란). HP 0.25배, 피해 3, 선딜 0.3s, 간격 1.4s, 속도 3.6. 한 번에 몰려 사슬 휘두르기(범위 공격)가 맛있는 유형.
**묻힌 혼** — 평소 Hidden(무덤). 플레이어가 4.5m 안에 들면 Windup 0.73s(땅이 갈라지는 예고 = 회피 창) 후 솟으며 붙잡기 피해 14, 범위 2.0m. 공격 후 Sink로 묻히고 6s 뒤 재매복. 솟는 동안(Windup 30f 이후)만 천도 가능.
**등급 효과** — (기획 확정 F-1b) 등급별 맺힘 배율은 쓰지 않음. 오래된 혼은 이동 ×0.8, 덩어리는 피해 ×1.3만. 대기시간 WAIT_FRESH 10·WAIT_LUMP 4 기존 규칙 유지.
**배치 1막** — 솔고개: 잔넋 위주 + 넋두리 소수 / 검은여울: 묻힌 혼 + 넋두리. 한 구역 최대 동시 원거리 2마리.

## 색(10-25 반영)
오래된 혼(old)은 기획 F-1b 에 따라 녹슨 적갈색(#6A3A2E 바탕, 발광 낮게). 덩어리만 짙은 보라 #9A5CFF. 주황은 파혼 전용이라 쓰지 않음. 같은 색키(soul_old)를 쓰는 기존 혼 모델·변형 12종·대기 고리도 함께 다시 뽑음.

## 코드팀 메모
- 모델 정면 −Y, 본 이름 Root/Body(+Arm,Orb / ArmL,ArmR). 이벤트 프레임으로 판정·탄 발사를 구동.
- 기존 4등급 단일 몸은 `soul_<grade>.glb` 그대로 유지(호환).
- 유니티 안 외관·타이밍은 미검증.
