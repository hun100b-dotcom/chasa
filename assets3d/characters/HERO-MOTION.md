# 주인공 이동 동작 · 보조 뼈 (코드팀용)

숫자의 근거: hud-controls-spec §3-2. 이동 5.5 m/s, 최고속 도달 0.08초, 멈춤 0.06초, 구르기 4 m·0.3초·무적 0.2초. 모두 60fps.
이 동작들은 `hero_chasa.glb` 안에 있다(뼈 28개 = 몸 16 + 보조 12, 동작 42개). 옛 동작과 뼈 이름은 그대로.

## 발이 안 미끄러지는 조건
Root를 **5.5 m/s** 로 옮기고 **Run을 속도 1.0배(30프레임=0.5초)** 로 재생. 다른 속도면 재생 속도 = 실제속도 ÷ 5.5.
(한 걸음 1.375 m, 한 바퀴 2.75 m, 초당 4걸음.) 검사값: 땅에 닿은 발끝의 세계 이동량 최대 0.0 mm/프레임.

| 동작 | 프레임 | 쓰는 법 |
|---|---|---|
| Run | 31(0~30, 30=0) 반복 | 이동 중. 0번에서 왼발이 닿는다 |
| Run_Start | 11 (0~10) | 정지→이동 입력 때. 속도 0→5.5를 5프레임에 올리는 값(`travel.speed_mps_per_frame`)대로 Root 가속. **10번 자세 = Run 0번** 이니 0~9만 재생하고 곧바로 Run 0번 |
| Run_Stop | 16 (0~15) | 입력이 끊길 때. Run **11번 프레임**(발이 닿기 직전)에서 시작. 속도 5.5→0을 4프레임에, 감속 거리 0.18 m. 끝 자세 = Idle 0번 |
| Run_TurnL / R | 31 반복 | Run과 같은 걸음 + 몸을 ±12° 기울임. 회전 중에 Run 대신 재생(150°/s 기준, 기울기 weight를 회전 속도에 비례해 주면 부드럽다) |
| Turn180_L / R | 13 | 제자리 180° 돌기(공격 중엔 즉시). Root 회전은 코드가 6프레임(0.1초)에 돌리고, 이 동작은 머리→가슴이 먼저 돌고 도포가 펄럭이는 시차만 더한다 |
| Roll | 19 (0~18) | 회피 구르기. **Root 이동 4.0 m**: 프레임별 속도표는 매니페스트 `Roll.travel.speed_mps_per_frame`(최고 15.2 m/s, 끝에 5.5로 맞춰 Run으로 바로 이어짐). **무적 2~14프레임**. 끝 자세 = Run 0번. 구르는 동안 몸 높이는 Root 뼈가 알아서(최대 0.38 m 들림) |

| Judge | 151 (0~150) 반복 | **처결 대기**: 무릎 꿇은 혼 앞에서 천도·파혼을 고르는 동안. 갓을 숙여 내려다보고, 혼불 든 왼손은 앞으로 내밀고, 철삭 든 오른손은 내려 힘을 뺀다. Idle→Judge 6프레임 크로스페이드 |

크로스페이드 권장: Idle↔Run_Start/Stop 0~1프레임, Run→Roll 2프레임. 옛 `Dodge`(앞으로 파고듦)는 남겨 두었다.
걷기(Walk)는 3.57 m/s에 맞는 보폭이다(5.5가 아님) — 느린 이동(대화 중 등)에만.

## 보조 뼈 12개 (자동 재생, 코드가 할 일 없음)
Skirt_F/B/L/R(도포 자락), Strap.L1/L2/R1/R2(갓끈), SashA1/SashA2/SashB1(허리띠 끝), Orn(노리개 술).
모든 동작에 가속·바람·허벅지·몸 기울기를 읽어 2차 스프링(약 3~5 Hz)으로 계산한 흔들림이 구워져 있다. 실시간 물리를 쓰려면 같은 뼈에 스프링 본을 붙이고 이 키를 끄면 된다.
구르기에서는 흔들림 강도를 0.3배로 줄였다.

## 다시 만들기
`python3 tools/art3d/hero_anim.py` (미리보기: `--sheets --side --only=Run,Roll`). 코드: hero_locomotion.py(걸음 계산·검사), hero_sec.py(보조 뼈).
수치(속도·보폭 등)는 hero_locomotion.py 맨 위 상수.
