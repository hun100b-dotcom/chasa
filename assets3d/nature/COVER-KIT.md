# 필드 바닥 채움 키트 (cover_*) — 코드팀 연결 안내

나무·덤불만 있던 필드의 빈 땅(보릿들·강변·길가)에 얹는 낮은 소품 26종과, 그 배치표입니다. 충돌 없는 장식입니다.

## 파일
- 모델: `assets3d/nature/cover_*.glb` 26종 (최대 708 삼각형, 풀 뭉치는 48~96). 원점=바닥 한가운데, 1유닛=1m.
- 배치표: `assets3d/layouts/field_cover.json` — `props: [{prop,x,y,rot,z,zone,tier}]`. 좌표는 field_5x5.json 과 같음(x=동, y=북). z=0 이라 땅 높이는 기존 소품처럼 코드가 얹는다.
- 생성기: `tools/art3d/cover_kit.py`(모델), `tools/art3d/field_cover.py`(배치표). 씨앗 고정이라 다시 돌려도 같다.
- 확인 그림: `assets3d/previews/cover_before_after.jpg`(왼쪽 위=전, 나머지=후), `cover_kit_50deg.png`(26종), `field_cover_density.png`(밀도 지도 전후).

## 숫자
- 총 27,059개: tier 1 = 5,067(보리 이랑 줄 2,422 + 돌·강변·길가·밭머리 소품), tier 2 = 21,992(풀·꽃·낙엽·이끼).
- 8m 칸당 소품 평균 1.0 → 5.2.

## 연결 방법
1. `python3 tools/build_field_data.py assets3d` — 기본은 **tier 1 만** field.json 에 합친다(`FIELD_COVER_TIER=1`). 모델은 Resources/Models/Field 로 자동 복사된다(.meta 는 유니티가 만든다).
2. 풀·꽃(tier 2)은 `FIELD_COVER_TIER=2` 로 켠다. 수가 많으니 **GPU 인스턴싱 + 거리 컬링**이 먼저다. 권장: tier 2 는 플레이어 45m 밖 숨김, tier 1 은 70m 밖 숨김. 같은 모델끼리 한 번에 그린다.
3. 충돌·그림자: 충돌 없음. 그림자는 풀·꽃·돌 무더기는 끄고, 보리 줄·돌담·유목·볏단만 켜도 충분.

## 구역별로 어떻게 채웠나
| 구역 | 채운 것 |
|---|---|
| 보릿들 | 지형 이랑(칸마다 남북 7줄, 1.04m 간격)과 같은 자리에 3D 보리 줄(푸른 것·익은 것을 넓은 구역 단위로 섞음). 밭머리에 돌담·볏단·말뚝·호미 소쿠리. 논두렁 자리(밭 가장자리 이랑)는 비움 |
| 길가 | 흙길 위는 비움. 길섶 풀밭에 돌탑·짚 흩어짐·돌·엉겅퀴·들꽃 |
| 강변(검은여울·개울) | 물 가까이 부들·짧은 갈대, 자갈, 유목, 젖은 흙, 상사화(붉은 저승 꽃). 물 속·강 조각 칸 위에는 두지 않음 |
| 물막이 골·폐당집 | 낙엽·이끼·돌·젖은 흙, 무덤 곁 상사화 |

## 함께 고친 것
`br_shore.glb`(강 물가 타일)가 한 가지 색 판이라 지형과 이음새가 보였다 → 풀 명암 얼룩과 자갈을 얹었다(삼각형 약 +700). 다른 br_* 모델은 그대로.

## 한계(솔직히)
- 탁 트인 풀밭은 여전히 '풀 질감'이 주인공이다. 소품만으로 잔디 느낌을 더 내려면 코드 쪽 풀잎 셰이더(지면 위 풀 흩뿌림)가 효과가 크다.
- 보리 줄은 쿼터뷰 50°에서 잘 읽히지만 낮은 카메라에서는 가는 막대처럼 보일 수 있다.
- 배치는 높이표·땅 그림(splat)·기존 소품 위치로 계산했다. 땅이나 소품이 바뀌면 `field_cover.py` 를 다시 돌린다.
