# 마을 사람 동작 (NPC-MOTION) — 21개 모델 공통 규칙

17명(모델 21개)이 모두 같은 16뼈 틀이라 유니티에서 컨트롤러 하나를 같이 쓸 수 있다. 동작 이름만 같으면 된다.
만든 곳: `tools/art3d/npc_motion.py`(동작), `tools/art3d/npcs.py`(조립). 다시 만들기: `python3 tools/art3d/npcs.py`.

## 1. 공용 동작 (21개 전부)
| 이름 | 반복 | 길이 | 쓰임 |
|---|---|---|---|
| Idle / Talk | 반복 | 96f / 120f | 서 있기, 말하기 |
| Walk | 반복 | 사람마다 46~76f | **걸음. 재생 속도가 아니라 이동 속도를 아래 표 `walk_speed_mps`로 맞춘다**(맞추면 발이 안 미끄러짐) |
| SitDown → SquatRest → StandUp | 1회 / 반복 / 1회 | 30f / 120f / 30f | 쪼그려 앉아 쉬기(일정에서 "앉는다·쉰다") |
| Startle → StartleHold → StartleRecover | 1회 / 반복 / 1회 | 22f / 60f / 36f | 혼이 가까이 올 때 움츠림 → 떨며 버팀 → 멀어지면 한숨 쉬며 풀림 |

- **놀람 사용법**: 혼이 NPC 반경 안에 들어오면 Startle(0.37초, 4프레임에 가장 크게 움츠림, 이벤트 flinch=4) → 끝나면 StartleHold. 혼이 반경 밖으로 나가고 1~2초 뒤 StartleRecover(이벤트 sigh=18) → Idle. 아이(N104·N204·N205)는 더 깊이 웅크리고 머리를 감싼다. 한 번 놀란 NPC는 몇 초 쉬었다 다시 놀라게 하면 자연스럽다.
- 걸음 중 놀람: Walk를 0.2초 안에 끊고 Startle로 바꿔도 되고, 그 자리에서 멈춘 뒤 Startle을 써도 된다(발 위치는 서 있는 자세로 이어짐).

모두 사람이 걷는 속도(0.6~1.2 m/s). 코드에서 NPC를 이 속도보다 빠르게 움직이면 발이 미끄러져 보이니, 표의 속도를 그대로 쓰거나 Walk 재생 속도를 `실제속도 ÷ 표 속도`로 맞춘다. 기준: 측정한 미끄러짐 ≤ 3mm/프레임(0.18 m/s 이하의 오차, 화면에서 안 보임).
걸음 모양: 물동이 인 아낙(곱단네)은 머리를 고정하고 한 팔로 받침, 쟁반(섭섭이)·지게(득보)·지팡이(동무)는 소품 쪽 팔 고정, 노인(당할미·갑술)은 구부정하게 짧게, 아이는 보폭 짧고 빠르게.

## 3. 하루 일정 ↔ 역할 동작
| 일정(npc_act1.json) | 동작 |
|---|---|
| 당할미 서낭당 지켜보기 / 부채 펼쳐 봄 / 명부 내려놓기 | Ritual(손 비비기+절), OpenFan(부채 살 세기), ReachUp(가지에 걸기) |
| 순임 나루 계단 장대에 등 달기 / 서낭당 천 묶기 | ReachUp(손 뻗어 매달기), RopeCoil(줄 감기) |
| 윤 소사네 아들 제사 | Offer(향로 받쳐 들고 고개 숙임), Bow(절) |
| 복남·언년이·삼돌이 노래놀이 | Play(손뼉+깡충) |
| 갑술 영감 정자 / 담뱃대 턴다 | Chant(요령 흔들며 선소리), TapPipe, SitDown·SquatRest |
| 곱단네·간난이 우물가 | DrawWater(두레박 끌어올리기), Laundry(쪼그려 빨래), Haggle(수다) |
| 덕만 보릿들 둑 / 소 고삐 감기 | HoldReins, SitDown+SquatCoil(앉아 고삐 감기) |
| 용득 새벽 풀무, 낮 대장간 | Bellows(풀무질), Hammer(망치질, 이벤트 hit=20이 쇠 치는 순간 → 쾅 소리·불꽃) |
| 득보·동무 고갯마루 / 장마당 | Walk(지게·봇짐), Haggle, SitDown·SquatRest |
| 은실 약방·역병막 사발 놓기 | Mix(약 갈기), PlaceBowl(쪼그려 사발 놓기, 이벤트 set_down=40), Haggle |
| 섭섭이 주막 등 걸기 | Serve(쟁반), ReachUp(등 걸기, 이벤트 tie=46), Haggle |
| 꼭지·차돌이 엿판 | WaveStick(엿 막대), Hawk(손나팔 호객), Haggle |
| 노경수 손주 흙에 글씨 | Read(책), Scribble(쪼그려 막대로 글씨, 이벤트 stroke) |
| 옥지기 옥문 앞 졸기 / 밤 호명 | Doze(꾸벅꾸벅, 140f에 퍼뜩 깸), Guard(좌우 둘러봄) |
| 사령 방 읽기 / 밤 순라 / 곤장 | ReadNotice(방 읽기), Guard, Stamp(곤장 쾅, 이벤트 hit=24) |

권장 연결: 일정 장소에 도착하면 Walk → Idle 0.3초 섞고 역할 동작 시작. 동작 끝(비반복)은 Idle로 0.2초 섞는다. 반복 동작은 일정 시간대 동안 계속 재생.

## 4. 알려진 한계 (정직하게)
- 치마·도포 입은 사람은 뼈 4개(Skirt_F/B/L/R, 주인공과 같은 이름)가 더 있고, 쪼그리면 이 뼈가 자락을 들어 올려 밑단이 땅에 묻히지 않는다(바지 입은 사람은 이 뼈를 쓰지 않으니 무시해도 됨). 뼈 수: 치마·도포 20개, 나머지 16개 + 안 쓰는 자락 뼈 4개.
- 손에 든 소품(쟁반·두레박 등)은 손뼈에 붙어 있어 손 모양이 단순하다(팔 각도만으로 표현).
- 위치 이동·충돌은 코드 몫이다. 이 동작들은 제자리 동작이다(Walk만 이동 속도 표를 따른다).
