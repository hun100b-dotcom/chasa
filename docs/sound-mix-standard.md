# 소리 크기 믹스 기준표 (기획·사운드, 2026-10-25)

숫자 원본: 저장소 `data/audio_mix.json`. 이 문서는 그 숫자를 왜 이렇게 정했는지 설명한다.

## 1. 한 줄 원칙
**효과(피할 정보·때린 손맛) > 음악 > 환경.** 예고음은 무엇에도 묻히지 않는다.

## 4. 잠깐 줄이기(더킹)
| 언제 | 줄일 것 | 배수 | 내려갈 때 / 돌아올 때(초) |
|---|---|---|---|
| 컷신 | BGM·환경 | 0.6 | 0.3 / 1.0 |
| 천도 시전 중 | BGM·환경·발소리 | 0.7 | 0.15 / 0.6 |
| 명부·설정 열림 | BGM·환경 | 0.6 | 0.2 / 0.4 |
| 품계 오름 | BGM | 0.6 | 0.05 / 1.5 |
| 보스 단계 전환 | BGM | 0.75 | 0.1 / 1.2 |
| 흑월이 사슬을 내려놓음 | BGM | 0.3 | 1.5 / 4.0 |

예고음(telegraph)과 bypass_cast 소리는 **절대 줄이지 않는다** — 피할 정보다.

## 5. 겹침 제한
- 같은 소리는 동시에 3개까지, 0.03초 안에 또 오면 버린다.
- 타격음은 동시에 4개까지. 요령방울은 한 번 휘두를 때 1번. 삼지창 2·3번째는 0.03초 늦게 0.7배.
- 처결 대기 똑딱은 가장 가까운 혼 하나만.
- 전체 목소리(AudioSource) 16개.

## 6. 폰
폰 스피커는 150Hz 아래가 거의 안 나온다. 중요한 소리는 사운드 쪽에서 400Hz~4kHz에 몸통을 넣어 두었다. 폰에서는 BGM만 0.85배 더.

## 7. 코드 연결 제안 (Sfx.cs·BgmPlayer.cs·ZoneAmbient.cs — 코드팀 소유)
```csharp
// AudioMix.cs (새 파일, 순수 C#): data/audio_mix.json 을 읽어 Bus(이름) / Duck() 을 준다
float bgm  = Mix.Bus(combat ? "bgm_combat" : "bgm_explore") * Mix.DuckNow("bgm") * Settings.Bgm;
float amb  = Mix.Bus("amb_zone") * (weatherOn ? Mix.Stack("amb_zone_when_weather") : 1f) * Mix.DuckNow("amb") * Settings.Sfx;
float wx   = Mix.Bus("amb_weather") * Mix.DuckNow("amb") * Settings.Sfx;   // 지금의 0.5f 자리
float step = Mix.Bus("footstep") * Mix.DuckNow("footstep") * Settings.Sfx; // 지금의 0.45f 자리
float ui   = Mix.Bus("ui") * Settings.Sfx;                                 // UI 는 더킹 없음
// 더킹 시작: Mix.Duck("cutscene") / 끝: Mix.Release("cutscene")  — 여러 개가 겹치면 가장 낮은 배수를 쓴다
```
설정에 '환경음' 슬라이더를 따로 두는 것은 다음 단계(지금은 효과음 슬라이더가 환경음도 함께 조절).
