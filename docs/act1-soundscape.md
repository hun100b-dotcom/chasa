# 1막 솔고개 주변 소리 — 서낭당 5곳 · 외톨이 야영지 · 처음 10분 길 (코드팀용) — 기획·사운드, 2026-10-26

> 배치표: `data/act1_soundscape.json`(좌표·거리·언제). 소리 파일은 `Resources/Audio/Sfx`, 재생 볼륨 1.0.
> 지금 1막은 들판 소리(`amb.field`)와 BGM·날씨만 깔린다. 그래서 어디를 걸어도 같은 소리다. 이 표는 **어디에 왔는지 귀로 알게** 한다.
> 코드 파일은 손대지 않았다. `ZoneAmbient`(2막·3막 구역 소리)와 같은 방식으로 붙이면 된다.

## 1. 세 겹
| 겹 | 무엇 | 어떻게 |
|---|---|---|
| 바탕 | 구역마다 반복음 하나(밤) | 구역 직사각형 = `field_camps.json`의 zones. 바뀌면 3초 교차. 낮은 지금처럼 `amb.field` |
| 자리 | 서낭당·대장간·넋길 입구·모닥불·고목·허수아비·개울 | 3D 반복음(spatialBlend 1, Logarithmic, 최소·최대 거리는 표). 소품 종류마다 가까운 몇 개만 |
| 흩뿌림 | 부엉이·먼 개·개구리·돌풍·덧문·보리 물결 | 구역마다 무작위 간격으로 한 번씩, 좌우 무작위 — **반복음의 이음매가 안 들리게 하는 게 이것**. 천도 중엔 멈춤 |

## 2. 서낭당 5곳 (아트 PR #37 모델에 맞춤)
| 곳 | 소리 | 무엇이 들리나 |
|---|---|---|
| ① 솔고개 마을 (188, 36) | `amb.seonang.solgogae` | 오방색 천 펄럭 + 금줄 한지 사락 + 촛불 타닥 — 가장 '살아 있는' 서낭당 |
| ② 보릿들 (160, 180) | `amb.seonang.boritdeul` | 짚·보리 이삭 서걱 + 솟대 삐걱 + 풀벌레 |
| ③ 물막이 골 어귀 (356, 324) | `amb.seonang.mulmagi` | 이끼 돌탑 물방울 + 물동이 퐁 + 개울 |
| ④ 검은여울 어귀 (108, 452) | `amb.seonang.geomeun` | 거의 고요. 끊긴 금줄 끝 톡, 재 스스스. **벌레 소리 없음**(역병) |
| ⑤ 폐당집 어귀 (자리 미정) | `amb.seonang.pyedang` | 고사목 삐걱 + 기와 달각 + 혼불 하나 웅(밤엔 크게) |
| 넋길 입구 3곳(밤) | `amb.soulpath.gate` | 혼불 다섯이 서로 다른 높이로 웅웅. 낮(`_off` 모델)엔 끔 |

멀리서도 구역이 달라 보이게 아트가 실루엣을 나눈 것처럼, 소리도 "무엇이 매달려 있나"로 나눴다. 눈을 감고 들어도 다섯 곳이 구분된다.

## 3. 외톨이 야영지 (field_camps `loner:true` 7곳)
| 때 | 소리 |
|---|---|
| 늘(무릎 꿇은 혼 자리, 3D 최소 1m·최대 9m) | `amb.loner` — 떨리는 들숨, 날숨, 가끔 훌쩍. 말 없음 |
| 차사가 8m 안에 처음 들어올 때 | `sfx.loner.notice` — 고개를 드는 옷자락 + 길게 '하아—'. 놀람이 아니라 기다림이 끝나는 쪽 |
| 처결하면 | 반복음을 0.5초에 끔(그다음은 늘 처결 소리) |
| 근처 무리와 싸우는 중 | 0.5배(묻혀도 됨 — 싸움이 끝나면 들리는 게 맞다) |

## 4. 처음 10분 길 — 걷는 순서대로 들리는 것 (밤 9시, 시계 멈춤)
| 시각 | 자리 | 들리는 것 |
|---|---|---|
| 0:20 | 서낭당 ①에서 깨어남 | `amb.seonang.solgogae`(가까이) + `amb.village.night`(바탕). 카메라가 내려오는 2초 동안 오방색 천이 가장 먼저 들린다 |
| 0:25~0:50 | 마을 남쪽 입구 → 우물 쪽 | 모닥불(202, 49.5) `amb.campfire.small`이 오른쪽에서 커졌다 작아짐. 덧문 덜컹·먼 개가 한 번씩 |
| 0:50~1:30 | 첫 혼 | 싸움 소리 + 바탕. 흩뿌림은 그대로(싸움이 끝나면 바로 밤이 돌아온 게 들림) |

| 7:00~9:00 | 보릿들 둑길 들머리, 거센 혼 | `sfx.elite.appear`가 들어오는 순간 바탕·흩뿌림을 0.6배로 2초(싸움 끝 징 `sfx.fight.end.jing` 뒤 되돌림) |
