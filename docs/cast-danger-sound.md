# 천도 시전 중 위험 — 소리 설계와 연결법 (코드팀용) — 기획·사운드, 2026-10-26 새벽

> 목표: **"마무리 순간이 가장 위험하다"를 귀로 느끼게.** 천도를 거는 1.5초 동안 세상은 먹먹하게 멀어지고,
> 시야(60%) 밖에서 다가오는 혼만 또렷하게 들린다. 들리는 쪽이 곧 혼이 있는 쪽이다.
> 지금 `Sfx.cs`·`JudgeSystem.cs`에는 손대지 않았다. 아래는 제안이고, 숫자는 `Balance`에 넣어 주면 기획이 조절한다.

## 1. 세 겹
| 겹 | 무엇 | 지금 | 바꿀 것 |
|---|---|---|---|
| ① 먹먹한 세상 | 전체 저역 통과 필터 20kHz → 1.2kHz (`visionP`) | 있음 | 음량도 함께 0.7배로(`CAST_WORLD_DUCK = 0.7`). 높은 소리만 깎으면 '멀어짐'이 덜 느껴진다 |
| ② 내 몸 | `sfx.tendo.cast`(드론) + **새 `amb.cast.heart`(심장 박동)** | 드론만 | 심장 박동을 같이 튼다. 위험도에 따라 빨라진다(아래 3) |
| ③ 시야 밖의 혼 | **새 경고음 `sfx.warn.*`** — 종류마다 다른 결, 방향·거리를 소리로 | 없음(화면 가장자리 표시만) | 아래 2 |

①은 경고음이 묻히지 않게 하는 바탕이다. 경고음은 모두 `bypass_cast_filter: true`이므로, 지금 `v.bypassListenerEffects = id == "sfx.enemy.telegraph"` 한 줄을 **`bypass_cast_filter` 값을 보도록** 바꿔 주면 된다. 지금 Sfx.cs는 `data/sfx_files.json`을 읽지 않으므로, ⓐ 그 파일을 `Resources`에 TextAsset으로 복사해 시작할 때 한 번 읽거나, ⓑ 간단히 id가 `sfx.warn.`·`sfx.cast.peak`·`amb.cast.heart`이거나 `.telegraph`로 끝나면 건너뛰게 한다(ⓐ가 맞고, 거센 혼·보스 예고음도 함께 맞게 된다).

## 2. 시야 밖 경고음 — 혼 종류별
| 혼 | 소리 | 결 |
|---|---|---|
| 보통 혼(Plain: 갓·해 넘긴·오래된) | `sfx.warn.plain` | 맨발 스윽 + 짧은 숨 |
| 넋두리(Wail) | `sfx.warn.wail` | 흐느끼는 높은 숨(멀리서 던지는 놈) |
| 잔넋(Mote) | `sfx.warn.mote` | 찍찍 잘게(떼) |
| 묻힌 혼(Buried) | `sfx.warn.buried` | 땅속 우르릉(아래에서) |
| 거센 혼·덩어리·사나운 적 | `sfx.warn.fierce` | 무거운 쿵 + 짧은 징 |
| (모두) 시야 밖에서 예비동작 시작 | `sfx.warn.wind` | '휙' 한 번 — 종류 소리 위에 얹음 |

**누구에게 울리나.** 천도 중(`Casting`)이면서 다음을 모두 만족하는 혼.
1. 살아 있고 무릎 꿇지 않았다.
2. 좁아진 시야 원 **밖**이다(`EdgeWarn.VisionRadius`와 같은 판정. 화면 가장자리 표시와 같은 대상).
3. 차사에게서 `CAST_WARN_RANGE = 12 m` 안이다.
4. 다가오는 중이거나(거리가 줄고 있음) 예비동작(`atk.Winding`) 중이다. 멀어지는 혼은 울리지 않는다(시끄럽지 않게).

가까운 순으로 **최대 3마리**만 울린다. 잔넋 떼는 한 마리로 친다(무리 중심).

**거리 → 반복 간격 · 크기**
| 거리 | 간격 | 크기 |
|---|---|---|
| 12 m | 1.0초 | 0.35 |
| 6 m | 0.55초 | 0.7 |
| 2.5 m 이하 | 0.3초 | 1.0 |
사이는 직선으로 잇는다. `Winding`이면 그 순간 `sfx.warn.wind` 한 번 + 간격을 최소(0.3초)로.

**방향 → 소리 위치.** 3D 소리(AudioSource 3D)는 쿼터뷰 카메라에선 위·아래 구분이 약하다. 그래서 2D 소리에 직접 값을 준다.
- 좌우: `panStereo = clamp(화면에서 본 방향의 x, −0.9, 0.9)` (카메라 오른쪽 벡터와 '차사→혼' 방향의 내적).
- 화면 위쪽(카메라에서 먼 쪽): 그 소리에만 `AudioLowPassFilter` 2.5kHz + 크기 0.85. 화면 아래쪽(가까운 쪽): 필터 없음.
  → "어둡고 작게 = 저 위쪽", "밝게 = 내 앞쪽"으로 익는다.
- 같은 혼은 음높이 ±3% 무작위만(종류가 헷갈리지 않게 크게 흔들지 않는다).
- 경고음 전용 AudioSource 3개를 따로 두면(일반 칸 10개와 다투지 않게) 끊김이 없다.

## 3. 마무리 순간이 가장 위험하다
천도 1.5초를 진행도 `p`(0→1)로 본다.
| 때 | 소리 |
|---|---|
| 시작 | 먹먹해짐(0.2초) + 드론 + 심장 `amb.cast.heart`(음량 0.3, pitch 1.0) |
| 진행 중 | 위험도 `danger = Σ(울리는 혼의 크기)`(최대 1)에 따라 심장 pitch `1.0 + 0.5·danger`, 음량 `0.3 + 0.5·danger` |
| **p ≥ 0.7 (마지막 0.45초)** | 심장 pitch에 +0.3 더(최대 1.8), 경고음 간격 ×0.7. 끝 0.5초 전에 **`sfx.cast.peak`** 한 번 — 이 동안 경고음·예고음·심장 말고 나머지는 0.4배 |
| 천도 끝 | 심장·드론을 0.15초에 끊고 `sfx.tendo.done`. 먹먹함이 풀리며 세상 소리가 돌아온다 = 안도 |
| 맞아서 끊김(있다면) | 심장을 바로 끊고 기존 `sfx.player.hurt` — 0.1초 무음 뒤 세상 소리가 확 돌아온다 |

`sfx.cast.peak` 직후 시야 밖 혼이 0.3초 간격으로 울리고 있으면, 플레이어는 "지금 끝낼까, 끊고 피할까"를 귀로 고르게 된다. 이게 이 설계의 핵심 순간이다.

## 4. Balance 상수 제안
`CAST_WORLD_DUCK = 0.7`, `CAST_WARN_RANGE = 12`, `CAST_WARN_MAX = 3`, `CAST_WARN_GAP_FAR = 1.0`, `CAST_WARN_GAP_NEAR = 0.3`, `CAST_WARN_NEAR_M = 2.5`, `CAST_WARN_PAN_MAX = 0.9`, `CAST_WARN_FAR_LP = 2500`, `CAST_HEART_PITCH_MAX = 1.8`, `CAST_PEAK_AT = 0.7`, `CAST_PEAK_DUCK = 0.4`.

## 5. 확인 방법(QA)
- 눈을 감고(또는 화면을 가리고) 천도를 걸었을 때, 왼쪽에서 오는 보통 혼과 오른쪽 위에서 노리는 넋두리를 말로 맞힐 수 있다.
- 다섯 종류 경고음을 처음 듣는 사람이 세 번 안에 구분한다(미리 듣기 페이지 `시연: 천도 중 위험` 참고).
- 천도 마지막 0.5초에 손에 땀이 나는 느낌이 있는가 — 기획이 직접 판정.
