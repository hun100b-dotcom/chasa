> 파일 위치: `Resources/Audio/Sfx/<id의 점을 밑줄로>.wav`. 크기는 파일에 맞춰 두었다.
> `Sfx.cs`, `Player.cs`, `JudgeSystem.cs`는 코드팀 파일이라 아래 내용은 붙일 자리를 제안하는 것이다.

## 1. 특성 소리: 무기 타격음 위에 "한 겹 더"

특성 소리는 타격음을 바꾸지 않는다. 타격음 바로 뒤에 0.04~0.1초 늦게 얹는다. 그래서 무기 소리는 그대로 들리고, 특성이 걸렸다는 것만 따로 들린다.
세 특성은 서로 다른 감각을 맡는다.
- 고정 = 땅
- 둔화 = 물결
- 표식 = 물방울

| id | 언제 | 소리 | 같은 무기 타격음과 갈리는 점 |
|---|---|---|---|
| `sfx.trait.pin` | 삼지창 3타가 일반·정예 혼을 고정(맞은 적이 여럿이어도 한 번). 3타음 0.04초 뒤 | 땅에 쿵 박힘 → 빗장 잠기듯 딸깍·딸깍(0.45초) | 3타음은 높은 쇠 "칙-칙-칙-쾅"이다. 고정은 **70 Hz 낮은 땅 소리와 마른 딸깍 두 번**이고 쇠 떨림이 없다 |
| `sfx.trait.pin.release` | 고정이 풀릴 때(1.0초, 정예 0.5초) | 흙 부스럭 + 틱(0.25초, 작게) | 풀린 줄 알게만 한다 |
| `sfx.trait.slow` | 요령 휘두름이 둔화를 걸 때. 휘두름 한 번에 한 번(맞은 적 수와 상관없음). 타격음 0.06초 뒤. 이미 둔화된 적만 맞았으면 0.5배 | 낮은 "우웅—"이 울렁이며 아래로 처짐(0.7초) | 요령 타격은 밝은 놋쇠 짤랑(무게중심 3500 Hz)이다. 둔화는 **쇳소리 없이 340 Hz 근처**에서 울렁인다. 짤랑 뒤에 물결만 남는다 |
| `sfx.trait.mark.1·2·3` | 붓 표식이 1·2·3개가 될 때. 붓 타격음 0.05초 뒤. 이미 3개면 소리 없음 | 먹물 방울 똑 / 똑똑 / 똑똑똑 + 사각 | 붓 타격은 넓게 퍼지는 잡음 "촥"이다. 표식은 **음이 있는 방울**이고, 개수가 늘수록 높아진다(620 → 780 → 980 Hz). 화면을 안 봐도 몇 개인지 귀로 센다 |
| `sfx.trait.name` | 붓 Q 「이름 쓰기」 | 붓 한 획 스으윽 → 먹 번짐 둥 → 인 꾹(1.1초) | 3타 "인(도장)"은 짧게 탁 찍는다. 이름 쓰기는 **길게 긋는 획이 먼저** 온다 |
| `sfx.trait.mark.splash` | 표식 있는 혼을 파혼할 때. 파혼음 0.12초 뒤. 옮긴 표식 수와 상관없이 하나 | 먹물이 파사삭 튐 → 둘레에 방울 톡톡(0.7초) | 이름 있는 혼을 파혼하면 내지 않는다(먹 튐 없음 규칙과 같게) |

보스는 고정이 안 걸리므로 `pin`이 울리지 않는다. 대신 맺힘 피해 +10%는 소리 없이 둔다. 둔화(−10%)와 표식은 보스에게도 그대로 소리를 낸다.

```csharp
// 붙일 자리(제안). 세 특성이 아직 코드에 없으니, 특성이 걸리는 바로 그 줄에 같이 넣으면 된다
if (pinnedCount > 0)  Sfx.PlayDelayed("sfx.trait.pin", 0.04f);            // 3타가 하나 이상 고정했을 때 한 번
if (pinEnded)         Sfx.Play("sfx.trait.pin.release");                   // 그 프레임에 풀린 것이 하나라도 있으면 한 번
if (slowedNew > 0)    Sfx.PlayDelayed("sfx.trait.slow", 0.06f);           // 새로 둔화된 적이 있으면
else if (slowedAny)   Sfx.PlayDelayed("sfx.trait.slow", 0.06f, vol: 0.5f); // 시간만 새로 고침
if (markAfter > markBefore) Sfx.PlayDelayed("sfx.trait.mark." + markAfter, 0.05f);   // 1·2·3
Sfx.Play("sfx.trait.name");                                                // 이름 쓰기가 걸릴 때
if (soul.Marks > 0 && !soul.Named) Sfx.PlayDelayed("sfx.trait.mark.splash", 0.12f);   // 파혼 때
```

## 2. 천도 시야 축소 소리: 위험하게 들리는가?

### 지금 하는 일 (`Sfx.cs` 185~203줄)

- 천도를 시작하면 화면 전체 소리를 저역 통과 필터로 20 kHz에서 **1.2 kHz**까지 0.25초 안팎에 깎는다.
- 시전 반복음 `sfx.tendo.cast`가 켜진다. 110 Hz 드론에 숨, 대금 기운이 섞이고, 음높이가 +12%까지 오른다.
- 시야 밖 적 경고(`sfx.warn.*` 6종)는 필터를 건너뛰어 또렷하게 들린다.

### 판단: **위험하게 들리지 않는다.**

1. **먹먹해지기만 해서 '안전한 방'처럼 들린다.** 바깥 소리가 작고 둥글어지고, 그 위에 차분한 드론이 깔린다. 그래서 귀는 "보호받는 중"으로 받아들인다. 눈은 시야가 60%로 좁아져 위험을 말하는데, 귀는 반대로 말한다.
2. **닫히는 순간을 알리는 소리가 없다.** 시야가 0.2초에 걸쳐 좁아질 때 소리로는 필터가 서서히 내려갈 뿐이다. "지금 바깥이 안 보이게 됐다"가 귀에 남지 않는다.
3. **위험은 경고음이 날 때만 생긴다.** 적이 시야 밖에서 다가오다가 예비동작에 들어가야 비로소 들린다. 그 전까지 "바깥 가까이에 무엇이 있다"는 긴장이 소리로 없다.
4. 경고 6종은 필터를 건너뛰어 잘 들린다. 이것은 맞다. 그대로 둔다.

### 고침: 새 소리 3개

모두 필터를 건너뛴다(`bypass_cast`). 드론은 그대로 둔다. 천도는 의식이라 차분해야 하므로, 위험은 드론 아래에 맥박으로만 깐다.

| id | 언제 | 소리 |
|---|---|---|
| `sfx.tendo.vision.close` | 천도 시전 시작. 시야가 좁아지는 0.2초에 맞춰 가장 커짐. 5초 안에 천도를 이어 하면 0.6배 | 귀 둘레 공기가 안쪽으로 훕 빨려 듦 → 다 닫힌 순간 낮은 맥 둥(0.4초) |
| `sfx.tendo.cast.danger` | 천도 중 반복. **볼륨 = 시야 밖 가장 가까운 적 거리**: 8 m 이상이면 0, 3 m 이하면 1. 없으면 0 | 귀 안의 낮은 심장 두-근(1초에 한 번, 52~60 Hz) |
| `sfx.tendo.vision.open` | 천도가 피하기나 맞음으로 끊겨 시야가 돌아올 때. 성공하면 `tendo.done`이 대신함 | 막혔던 귀가 트이듯 바깥 소리가 휙 돌아오는 숨(0.3초) |

```csharp
// Sfx.cs 천도 캐스팅 부분(제안)
// (왜) 먹먹 필터만 있으면 천도가 '안전한 방'처럼 들린다. 닫히는 순간 + 바깥 적 거리 맥박으로 위험을 귀에 남긴다
if (judge.Casting && !wasCasting) PlayInternal("sfx.tendo.vision.close", 1f, 0f);
if (!judge.Casting && wasCasting && !judge.LastTendoDone) PlayInternal("sfx.tendo.vision.open", 1f, 0f);
float near = judge.NearestUnseenEnemyDist();   // 시야 밖 적만(없으면 큰 값). EdgeWarn 이 이미 계산하는 값
dangerLoop.volume = judge.Casting ? Mathf.InverseLerp(8f, 3f, near) * SaveStore.Settings.Sfx : Mathf.MoveTowards(dangerLoop.volume, 0f, Time.unscaledDeltaTime * 6f);
dangerLoop.bypassListenerEffects = true;   // 필터를 건너뛰어 맥박이 먹먹해지지 않게
wasCasting = judge.Casting;
```

- 필터 바닥값 1.2 kHz는 그대로 둔다. 1.0 kHz보다 낮추면 폰 스피커에서 바깥 소리가 거의 사라진다.
- 시연 `demo_tendo_vision`의 순서: 천도 시작(닫힘) → 바깥 적이 다가올수록 맥박이 커짐 → 경고(스윽, 휙) → 피하기로 끊김(돌아옴).
