# 1막 마을 사람 실루엣 보강 + 장례·제사 애도객

> 대상: 마을 사람 17명(21모델) 보강, 새 애도객 10모델. 만든 곳 `tools/art3d/mourners.py`, `npcs.py`, `npc_motion.py`. 실루엣 점검 `tools/art3d/npc_silhouette.py`.
> 모델 위치 `assets3d/npcs/` (유니티용 복사본 `unity/Assets/Resources/Models/Npc/`). 같은 16뼈 틀이라 마을 사람 컨트롤러를 그대로 같이 쓴다.

## 1. 마을 사람 보강 (실루엣으로 나이·직업이 읽히게)
쿼터뷰에서는 얼굴보다 머리 위 모양·밑단 폭·어깨선이 먼저 보인다. 색을 지운 그림자판으로 점검하니 치마 입은 여자 다섯이 거의 같은 종 모양이었다. 고친 것:
| 사람 | 바꾼 것 | 읽히는 것 |
|---|---|---|
| 당할미 | 치마 폭 좁힘 + 왼손 지팡이 | 늙고 구부정한 무녀 |
| 곱단네 | 치마 폭 넓힘 + 흰 앞치마 | 중년 아낙(물동이) |
| 간난이 | 중간 폭 + 흰 앞치마 | 젊은 아낙(두레박) |
| 은실 | 좁은 치마 + 등의 약초 망태 | 약방 처녀 |
| 섭섭이 | 중간 폭 + 쟁반 | 주막 처녀 |
| 덕만 | 머리수건 → 삿갓, 어깨에 짚단 | 소장수 아들(용득·동무와 구별) |
앞치마 유무가 아낙/처녀를 가르는 규칙이다. 전후 비교: `assets3d/previews/npc_silhouette_before.png` / `npc_silhouette_after.png`.

## 2. 애도객 10모델
삼베·소복 색(회갈 #BDB195, 흰 #E3DCC8)으로 평소 마을 사람의 선명한 색과 구별된다. 주황은 쓰지 않았다.
| 모델 | 누구 | 읽히는 표시 | 동작 |
|---|---|---|---|
| M01 | 맏상주(지팡이) | 굴건·베옷·상장·허리 새끼띠 | Walk(행렬), Bow, Wail |
| M01b | 맏상주(노제) | 위와 같고 술잔, 지팡이 없음 | PourCup(잔 올림→붓기→절), Bow, Wail |
| M02 | 상주 아내 | 풀어헤친 머리·흰 수건 | Wail, Bow |
| M03 | 막내딸 | 땋은 머리·품에 안은 짚신 | HugShoes(울지 않고 안고 섬), Walk(안고 걷기) |
| M04a/b | 상여꾼 | 어깨의 긴 채(오른/왼 어깨) | Walk(채 멘 걸음, 박자 맞춘 출렁임) — 여덟 명은 A·B 번갈아 복제 |
| M05 | 만장잡이 | 키보다 높은 만장 깃대 | HoldFlag, Walk |
| M06 | 이웃 아낙 | 흰 수건·떡 광주리·회색 치마 | Walk, MournStand |
| M07 | 조문 노인 | 흰 도포·검은 갓·지팡이 | Walk(짧고 느림), Bow |
| M08 | 어린 상제 | 큰 굴건의 작은 아이 | Walk, Weep |
| M09 | 무명 올리는 사람 | 흰 무명 한 필을 안음 | Walk, Bow |
요령잡이는 기존 갑술 영감(N105, Chant 동작), 아들은 N103도 쓸 수 있다.
- **공통 동작** (애도객 전원 + 마을 사람 21모델): Idle, Walk, SitDown/SquatRest/StandUp, **Weep**(서서 울기, sob 이벤트), **MournStand**(고개 숙이고 서기, wipe 이벤트). 애도객은 Bow도 있다.
- **Wail**(애고곡): SitDown → Wail → StandUp 순서로 잇는다. 이벤트 pound=14가 땅을 치는 순간(쿵 소리·먼지 한 점).
- **의도**: 애도객은 차사를 보지 못한다(장례 연출 규칙 1~2). 그래서 Startle·Talk·Work를 넣지 않았다. 행렬이 차사를 지나칠 때 피하는 동작이 필요 없다.
- 걸음 속도(Walk 재생 = 이동 속도): 0.42~0.57 m/s로 모두 느린 행렬 걸음(노인 0.42, 아이 0.46, 상여꾼 A 0.571·B 0.554, 상주 0.571). 발 미끄러짐은 최대 0.81 mm/프레임. 행렬은 가장 느린 이에 맞춰 대열 속도를 정하고 각자 `walk_speed_mps`로 재생 속도를 나누면 발이 안 미끄러진다(값은 `_mourner_manifest.json`).
- M05 키 2.94 m는 만장 깃대를 포함한 값이다(몸은 1.7 m대).
- 상여(prop_sangyeo)와 조합: 상여꾼 채는 모델마다 2.6 m 한 토막이라 여덟을 일렬(앞뒤 간격 약 1.3 m)로 세우면 이어 보인다. 정확한 위치는 코드팀 행렬 배치에 맡긴다.
