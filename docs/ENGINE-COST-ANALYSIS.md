# 엔진 비용·기술 분석: Unity vs Godot (2026-10-24 재조사)

> P1-001 보강. 결정은 오너. 숫자는 공식 페이지에서 직접 읽은 것만 "확인"으로 표시, 나머지는 "추정/미확인".

## 1. 비용 (공식 자료, 조회일 2026-10-24)

| 항목 | Unity | Godot |
|---|---|---|
| 엔진 라이선스 | **Personal 무료**: 매출+투자 합계 연 $200,000 이하. 초과하면 **Pro $2,310/년/좌석**(월 결제 $210). Enterprise는 매출 $25M 초과 (확인: [unity.com/products/pricing-updates](https://unity.com/products/pricing-updates), 2025-11-10 발표, Pro·Enterprise +5% 2026-01-12 적용) | **MIT 라이선스, 영구 무료**. 매출 구간·좌석·로열티 없음 (공식 FAQ 근거, [docs.godotengine.org FAQ](https://docs.godotengine.org/en/stable/about/faq.html)) |
| 런타임 수수료(설치당 과금) | **취소됨** (2024-09 Unity 발표: [unity.com 블로그](https://unity.com/blog/unity-is-canceling-the-runtime-fee)). 단 2023년 소급 과금 시도 전력이 있어 "정책 변경 위험"은 남음 | 없음 |
| 스플래시(로고 화면) | Unity 6 Personal에서 **선택 가능**(끌 수 있음) (확인: 위 pricing 페이지) | 없음 |
| 웹·모바일 배포 비용 | 엔진 추가요금 없음. 스토어 수수료(앱스토어·구글플레이 등)는 엔진 무관 | 엔진 추가요금 없음. 동일 |
| 콘솔 | 공식 지원 경로(각 플랫폼 계약 필요) | **공식 콘솔 포트 없음** ([godotengine.org, 2024-09-03](https://godotengine.org/article/about-official-console-ports/)). 서드파티 업체 이용 — 비용 미확인 |
| 에셋·툴 | 에셋 스토어 방대(유료 다수). 한국어 자료 풍부 | 에셋 적음, 대부분 무료/직접 제작. 우리는 도형·AI 생성 에셋 방침이라 영향 작음 |
| 1인 개발 시간 비용 | 에디터 GUI 작업 필요(장면·프리팹·재질). 설치 25GB, 관리자 권한(UAC)·오너 계정 로그인 필요 → **오너 손이 들어감** | 텍스트 파일만으로 AI가 혼자 개발·빌드·테스트 (클라우드에서 이미 검증) |

### 비용 시나리오 (엔진 사용료만, 환율 별도)
| 상황 | Unity | Godot |
|---|---|---|
| 출시 전·소규모 (매출+투자 ≤ $200K) | $0 | $0 |
| 매출/투자 > $200K, 개발자 1명 | **$2,310/년** (≈ 월 $193) | $0 |
| 개발자 3명 | $6,930/년 | $0 |
| 매출 로열티·설치 수수료 | 없음(런타임 수수료 취소) | 없음 |
→ **1인 개발 단계에서 두 엔진의 엔진 사용료 차이는 $0 vs $0.** 차이는 매출 $200K를 넘긴 뒤부터 생긴다(성공했을 때의 비용).

## 2. 기술 분석

| 항목 | Unity | Godot | 근거 |
|---|---|---|---|
| 성능(이 게임 규모: 적 수십 마리, 쿼터뷰) | 충분 | 충분 | 같은 숫자로 만든 두 시험판 모두 문제 없었음(오너 체감 "비슷"). 대규모(수백~수천) 최적화는 Unity DOTS가 유리 — 우리 목표 규모 밖 |
| 모바일 | 최고 수준 도구(프로파일러 등) | 사용 가능(Compatibility 렌더러) | 일반 지식, 우리 모바일 실측 없음 |
| 웹 | Web 빌드: iOS Safari 15+/Android Chrome 58+, PWA 가능 ([Unity 6.6 문서](https://docs.unity3d.com/Manual/webgl-browsercompatibility.html)) | WebAssembly + WebGL 2.0 필요 ([Godot 문서](https://docs.godotengine.org/en/stable/tutorials/export/exporting_for_web.html)). 우리 빌드: wasm 39MB, 서버 설정 없이 동작 | Unity 웹 빌드 크기는 **미측정**(PC에 Unity 없음) |
| 컷신·카메라 | **Timeline·Cinemachine**이 강력 → "실시간 시네마틱 컷신"(VISION §6)에 유리 | AnimationPlayer로 가능하나 카메라 연출 도구는 직접 만들어야 함 | 일반 지식 |
| AI 단독 개발 | 소스는 C#으로 작성 가능(포팅 완료, 컴파일 미검증)하나 **에디터 설정·로그인·빌드는 사람 PC 필요** | **텍스트만으로 전부 가능**, 헤드리스 테스트 49개 자동화 | 이 프로젝트 실측 |
| 학습 자료·인력 | 한국어 자료·채용 시장 압도적 | 자료 증가 중, 숙련자 적음 | 일반 지식 |
| 장기 리스크 | 가격 정책 변경 전력(2023). 대신 대기업 지원 | 재단 소규모(공식 글: 유급 직원 약 10명), 콘솔 지원 약함. 대신 MIT라 소스 보유·정책 변경 불가 | 위 공식 글 |

## 3. 추천
- **지금(1인·AI 개발): Godot.** 비용 차이는 없고(둘 다 $0), 오너가 에디터·로그인·관리자 권한을 만지지 않아도 AI가 끝까지 만들 수 있다는 점이 결정적. (기존 비교표 4.15 vs 3.85 결론 유지)
- **Unity로 갈아탈 신호(재검토 조건)**: ① 콘솔 출시를 퍼블리셔와 확정 ② Unity 경력 개발자 채용 ③ 컷신 연출이 Timeline 수준 없이는 안 풀릴 때. 그 시점 이식 비용은 지금 시험판(같은 숫자로 포팅)을 기준으로 추정 가능.
- 성공 시 비용: 매출 $200K 초과 후 Unity는 좌석당 연 $2,310 — 1~3인 팀이면 큰 부담은 아니다. 즉 **비용만으론 Godot 우위가 결정적이지 않고, "AI 단독 개발 가능성"이 결정 요인**이다.

## 4. 한계(숨기지 않을 것)
- Unity 웹 빌드 크기·모바일 성능은 직접 측정하지 못했다(Unity 미설치).
- Godot 서드파티 콘솔 포팅 비용은 공식 자료에 숫자가 없어 확인 못 함.
- 원화 환산은 환율에 따라 달라 USD로만 표기.
