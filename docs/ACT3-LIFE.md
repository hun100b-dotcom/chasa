# 3막 ⑤ 갯마을 · ⑥ 도성 아랫마을 생활 소품 (아트)

## 왜
배치표를 구역별로 세어 보니 1만 ㎡당 소품이 난파 여울 2.2, 성문 밖 2.2, 움막촌 5.1, 포구 7.1, 소금밭 6.7개로 비어 있었다(저잣거리 14.8, 곶 17.6은 괜찮음).
사람이 살고 일한 흔적을 채워 텅 빈 느낌을 없앤다.

## 소품 34종 (`assets3d/act3/a3*_*.glb`, Unity `Resources/Models/Field/`에도 복사)
| 접두 | 구역 | 소품 |
|---|---|---|
| a3h_ | 포구·소금밭 | 생선 말림대, 엎어 둔 배, 밧줄 말뚝, 궤짝 더미, 미역 줄, 조개 바구니, 땔감 더미, 타르 통(Light_), 소금 가마니, 소금 지게, 소금물 구유, 소금막(Light_) |
| a3c_ | 해안·여울·곶 | 유목, 굴 붙은 갯바위, 갯풀, 게통발, 난파선 뼈대, 조개 더미 |
| a3g_ | 성문 밖 눈밭 | 눈 덮인 고사목, 눈 울타리, 버려진 수레, 화톳불 통(Light_), 눈 돌탑, 볏짚단, 마른 떨기나무 |
| a3s_ | 움막촌·다리 밑 | 빨래줄, 흙 화덕, 독 받침, 거적 천막, 판자 더미, 닭장 |
| a3k_ | 저잣거리 | 궤짝, 옷감 시렁, 통 둘 |
- 규약은 act3_kit과 같다(1유닛=1m, 원점=바닥 한가운데, 정면=-Y). 불빛은 따뜻한 등불색, 주황(파혼)은 쓰지 않았다.
- 만든 스크립트 `tools/art3d/act3_life.py`, 미리보기 `assets3d/previews/act3_life_{a..e}_50deg.png`, 크기·삼각형 `assets3d/act3/_report_act3_life.json`.

## 배치표
`tools/art3d/place_act3_life.py` → `assets3d/layouts/act3_east_extra.json`(209) · `act3_west_extra.json`(154) · `act3_extra_report.json`.
기존 `act3_east_layout.json`·`act3_west_layout.json` 옆에 **같이 읽는다**(형식 같음). 길 1.5m+반경·장소 점·겹침·땅 높이는 기존 규칙 그대로. 바닷가 소품은 땅 높이 -0.7~1.4에만 놓아 썰물에 드러나고 밀물에 잠긴다.
구역별 밀도(1만 ㎡당): 포구 7→35, 소금밭 7→30, 난파 여울 2→32, 성문 밖 2→28, 움막촌 5→30, 저잣 15→23, 다리 밑 9→15.

## 코드팀 할 일
1. `build_field_data.py`가 두 `*_extra.json`을 기존 배치표와 함께 읽게 한다.
2. 소품이 늘었으니 컬링·LOD 확인(갯풀·떨기나무는 같은 모델이 수십 개라 인스턴싱 권장).
3. Unity에서 눈으로 확인한 적 없음(걷기·겹침·썰물 때 잠김).
