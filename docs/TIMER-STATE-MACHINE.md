# P1-014 처결 타이머 상태머신 설계 (1차)

> 상태머신 = 캐릭터가 "대기 / 피격 / 무릎 / 천도 중 / 소멸" 같은 상태 사이를 **정해진 규칙으로만** 오가게 만드는 설계도.
> 근거: COMBAT-SPEC 1-1~1-4, 1-2 W-001~W-005, T-001~T-008. 구현 기준: `godot/enemy.gd`, `godot/player.gd` (자동 검사 42개로 확인).
> 🔴 표시는 스펙 공백을 **임시로 채운 곳**. 기획 확정(P1-041) 전까지 바뀔 수 있다.

## 1. 적(혼)의 상태

| 상태 | 뜻 | 들어오는 조건 | 나가는 조건 |
|---|---|---|---|
| ACTIVE | 싸우는 중(쫓기·예비동작·공격) | 생성/부활, 대기 시간 초과 | 맺힘 0 → KNEEL |
| KNEEL | 처결 대기. 타이머가 흐른다 | 맺힘 0 | 천도 시작 → SENDING / 파혼 → GONE / 시간 초과 → ACTIVE 🔴 |
| SENDING | 천도 캐스팅 받는 중. 타이머 정지 | 플레이어가 천도 시작 | 캐스팅 완료 → GONE(천도) / 플레이어 피격 → KNEEL 🔴 |
| GONE | 떠났거나 터짐. 잠시 뒤 새 혼으로 부활(소환된 적은 그대로 삭제) | 천도 완료, 파혼 | 부활 지연(1.6초) 후 ACTIVE |

```
ACTIVE --맺힘0--> KNEEL --천도 시작--> SENDING --1.5초(연속 0.8)--> GONE
                   |  ^                    |
                   |  +---- 피격 중단 🔴 ---+
                   +--파혼(즉시)------------------------------------> GONE
                   +--대기 초과 🔴--> ACTIVE (맺힘 50%, 0.4초 경직)
```

- 대기 시간: 갓 죽은 10초 / 해 넘긴 7초 / 오래된 4초 (W-001~003). 덩어리(W-004)는 스펙상 "대기 없음·천도 불가"인데, 지금은 **4초 동안 파혼만 받는** 임시 해석 🔴.
- 같은 적을 두 번 처결할 수 없다: KNEEL에서만 천도·파혼 명령이 먹는다.

## 2. 플레이어 상태 (처결 관련만)

| 상태 | 처결 명령 |
|---|---|
| FREE | 받는다. 사거리(2.8m) 밖이면 먼저 걸어간다 |
| ATTACK | 후딜(recover) 구간에서만 끊고 받는다. 휘두르는 도중엔 무시 |
| PULL | 무시 |
| CAST(천도 중) | 새 처결 무시. 피격 시 중단 🔴 |
| HURT(0.3초 휘청) | 무시 |

## 4. 규칙 요약 (구현 시 지킬 것)
1. 상태 변경은 `Enemy`의 함수(`take_hit`, `begin_sending`, `cancel_sending`, `finish`)로만 한다. 밖에서 `state`를 직접 바꾸지 않는다.
2. 모든 수치는 `config.gd`에 스펙 ID와 1:1로 둔다.
3. 상태를 늘릴 때는 이 표를 먼저 고친다.
