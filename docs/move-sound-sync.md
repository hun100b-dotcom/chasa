# 조작 수정에 맞춘 발소리·구르기·착지 + 처결 대기 신호 점검 (기획·사운드, 2026-10-26 KST)

> 기준: `planning/controls/controls-feel-check.md` 조작 수정.
> - 구르기 섞기 0.033초
> - 키를 떼면 0.18 m 미끄러지며 멈춤(Run_Stop 0.25초)
> - 발소리 한 걸음 1.375 m(초당 4걸음)
> - Run_Start 0.167초
>
> 소리 파일은 기획·사운드가 고쳤다. `Player.cs`·`JudgeSystem.cs`는 코드팀 파일이라 아래는 **제안**이다.

## 1. 한눈에

| 동작 | 지금 소리 | 맞나 | 한 일 / 제안 |
|---|---|---|---|
| 걸음(초당 4번) | 땅 재질 발소리 6종×4. 모두 0초에 시작, 가장 큰 곳 0.002~0.014초, 길이 0.14~0.29초 | ✓ 소리 자체는 맞음 | `FOOTSTEP_STRIDE_M` 1.15 → **1.375**는 수정 목록대로 넣으면 된다. 소리는 그대로 |
| 첫 걸음(출발) | 남은 걸음 거리(`strideLeft`)가 지난번 걷던 값 그대로 남아 있음 | ✗ 출발 첫 소리가 들쭉날쭉. 발이 땅에 닿기 전에 날 때도, 한참 늦게 날 때도 있다 | 출발할 때 `strideLeft = 0.6 m`로 맞추기. 5.5 m/s로 0.1초 가속하면 Run_Start가 끝나는 0.167초쯤 첫 발이 닿는다 |
| 멈춤(키 뗌, 0.18 m 미끄러짐) | 소리 없음. 0.18 m로는 다음 발소리 거리에 못 미친다 | ✗ Run_Stop 자세에서 발을 딛는데 조용하다 | 키를 떼고 **0.1초 뒤 발소리 한 번(0.7배)**. 마지막 발소리에서 0.4 m 넘게 걸었을 때만. 그 뒤 `strideLeft = 0.6`으로 되돌림 |
| 구르기 시작(섞기 0.033초) | `sfx.dodge`: 가장 큰 곳 0.072초 | △ 몸은 0.033초에 움직이는데 쉭이 조금 늦다 | **고침:** 쉭의 가장 큰 곳을 **0.05초**로 당김 |
| 구르기 가운데 | 땅 닿는 소리 없음 | ✗ 구르는데 '공중 회피'처럼 들린다 | **고침:** 0.13초에 어깨가 땅에 닿는 낮은 툭과 옷 쓸림을 더함(쉭보다 4 dB 작게) |
| 구르기 끝 착지(0.32초 중 0.28초쯤 발 디딤) | 없음 | ✗ | `dodgeT`가 0.28초를 넘는 순간 **땅 재질 발소리 한 번**(`Sfx.PlayStep`). 흙·물·논에 따라 저절로 달라진다. 그 뒤 `strideLeft = 1.375`(구르고 바로 달려도 발소리가 두 번 겹치지 않게) |
| 매듭 걸음(사슬 돌진) | `sfx.dodge`를 같이 씀 | △ 이제 구르기 소리에 땅 닿는 툭이 들어가 돌진과 안 맞는다 | 옛 쉭만 있는 **`sfx.dodge.dash`**(새)를 `CommandKnotDash`에서 쓰기 |

## 2. 코드 제안 (Player.cs)

```csharp
// (1) 출발: 멈췄다 다시 걷는 순간(지금 walkSpeed 를 처음부터 올리는 그 줄 옆)
// (왜) Run_Start 가 끝나는 0.167초쯤 첫 발이 땅에 닿는다. 그때 첫 발소리가 나도록 걸음 거리를 맞춘다
if (Time.time - lastStepTime > 0.1f) { walkSpeed = full * Balance.MOVE_START_FRAC; strideLeft = 0.6f; }

// (2) 멈춤: WASD 를 떼어 0.18 m 미끄러지게 하는 곳에서
// (왜) Run_Stop 자세가 발을 딛는데 0.18 m 로는 다음 발소리 거리에 못 미쳐 조용했다
if (Balance.FOOTSTEP_STRIDE_M - strideLeft > 0.4f) stopStepT = 0.1f;   // 0.1초 뒤 발소리 0.7배
strideLeft = 0.6f;
// Tick 에서: if (stopStepT > 0 && (stopStepT -= dt) <= 0) Sfx.PlayStep(w, wet, 0.7f);

// (3) 구르기 착지: TickDodge 안
// (왜) 0.32초 구르기 끝(0.28초)에 발을 디딘다. 땅 재질 발소리라 물·흙·논에서 저절로 달라진다
if (!dodgeLanded && dodgeT >= 0.28f) { dodgeLanded = true; Sfx.PlayStep(w, wet, 0.9f); strideLeft = Balance.FOOTSTEP_STRIDE_M; }
// CommandDodge 에서 dodgeLanded = false. 매듭 걸음(CommandKnotDash)은 착지 발소리는 같게, 시작 소리만 "sfx.dodge.dash"
```

`Sfx.PlayStep`에 크기 배율 인자(`float vol = 1f`)를 하나 더하면 된다. 지금 크기는 0.45로 고정되어 있다.

## 3. 처결 대기 남은 시간 신호 (10초 갓 죽은 · 7초 해 넘긴 · 4초 오래된)

지금 규칙(`JudgeSystem.TickWaitTick`)을 그대로 돌려 보았다(60프레임):

| 대기 | 똑딱 수 | 첫 세 번 | 마지막 1.5초 안 똑딱 | 가장 짧은 간격 |
|---|---|---|---|---|
| 10초 | 21번 | 0.32 · 1.30 · 2.20초 | 7번 | 0.19초 |
| 7초 | 15번 | 0.32 · 1.28 · 2.13초 | 6번 | 0.18초 |
| 4초 | 8번 | 0.32 · 1.25 · 2.00초 | 5번 | 0.22초 |

### 문제 3개

1. **남은 '시간'이 아니라 남은 '비율'로 빨라진다.**
   - 간격 = 남은 비율에 따라 0.15~1.0초이다. 그래서 4초짜리 오래된 혼도, 10초짜리 갓 죽은 혼도 처음 몇 번은 똑같이 1초 간격으로 운다.
   - 귀로는 "이 혼은 시간이 짧다"를 알 수 없다.
   - 제안: 간격을 **남은 초**로 정한다.
     ```csharp
     waitTickT = Mathf.Lerp(0.18f, 1.0f, Mathf.Clamp01((s.WaitLeft - 1.5f) / 6f));
     ```
   - 이렇게 하면 7.5초 넘게 남았을 때는 1초 간격이고, 1.5초가 남으면 0.18초까지 빨라진다.
   - 오래된 혼(4초)은 처음부터 약 0.5초 간격이라 듣자마자 급하다. 갓 죽은 혼은 처음 2.5초 동안 느긋하다.
2. **똑딱이 서로 번졌다.**
   - 오래된 혼 똑딱은 0.3초, 해 넘긴 혼은 0.25초였다. 가장 짧은 간격 0.18~0.22초보다 길었다.
   - **고침:** 둘 다 0.18초로 줄이고 끝을 부드럽게 닫았다.
   - 갓 죽은 혼의 '두-근'(두 번째 박 0.14초)은 빨라질수록 심장이 뛰는 느낌이라 그대로 두었다. 숫자 혼(0.12초)도 그대로다.
3. **마지막 1.5초에 소리가 쌓인다.**
   - `sfx.wait.final`(1.5초, 숨 들이켜며 올라가 1.4초에 가장 큼) 위로 똑딱이 5~7번 더 겹친다.
   - 제안: `wait.final`이 울리면 **똑딱을 멈춘다.** 올라가는 소리 자체가 마지막 셈이다.
     ```csharp
     if (waitFinalDone) return;
     ```
     위 줄을 `waitTickT -= dt;` 바로 앞에 넣는다. 고리 맥박(0.5초마다)은 그대로 두어 눈으로도 센다.
