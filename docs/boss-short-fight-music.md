# 보스 곡을 확정된 싸움 길이에 맞추기 (기획·사운드, 2026-10-26 KST)

> 근거: 기획팀 확정 보스 목표 길이(10-26): 1막 1.5~2분 · 2막 2~2.5분 · 3막 2.5~3분 · 흑월 3~4분. "보스 곡은 2분 반복, 맺힘 50%에서 국면 전환."
> (기획 시뮬 `planning/combat/s1-boss-curve-check.md`의 23~57초는 지금 맺힘값의 어림이었다. 목표 길이는 맺힘을 그만큼 올린다는 뜻이라, 곡은 목표 길이를 기준으로 맞춘다.)
> 바꾼 곳: `data/bgm.json` → `layers.boss`, `heukwol_2`. 2·3막 임시 보스 곡 8개(`tools/bgm_temp_render.py`). `BgmPlayer.cs`는 코드팀 파일이라 아래는 제안이다(지금 보스 층은 아직 코드에 없다).

## 1. 단계마다 들리는 길이

맺힘 50%에서 2단계로 넘어가므로, 한 단계는 싸움의 절반이다.

| 막 | 싸움 | 1단계 들리는 길이 | 2단계 들리는 길이 |
|---|---|---|---|
| 1막 (B-01~B-03) | 90~120초 | 45~60초 | 45~60초 |
| 2막 (B-05~B-08) | 120~150초 | 60~75초 | 60~75초 |
| 3막 (B-09~B-11) | 150~180초 | 75~90초 | 75~90초 |
| 흑월 2차 (B-12) | 180~240초 | 1·2단계(맺힘 100→40%) 110~145초 | 큰물(40→15%) 45~60초 |

**원칙: 어느 단계도 곡 한 바퀴를 넘지 않는다.** 되풀이가 들리지 않고, 곡의 큰 흐름(차오름 → 절정)이 한 단계 안에 담긴다.

## 2. 무엇이 안 맞았나

| 곡 | 옛 안 | 문제 |
|---|---|---|
| 1막 `bgm_solgogae_boss`(오너 곡, 142.65초) | 1단계 이 곡 → 2단계 `bgm_solgogae_combat`(41.85초) | 1단계는 45~60초만 들린다. 그런데 이 곡의 절정은 **64.6~115초**에 있다. 그래서 절정을 한 번도 못 듣고 끝난다. 2단계 전투 곡은 45~60초 동안 1.1~1.4바퀴 되풀이된다 |
| 2·3막 임시 `_boss`(150초) · `_boss_p2`(90초) | — | 1단계는 북만 치는 시작이 12초나 돼서 싸움 처음이 약하다. 2단계 90초는 3막(75~90초)에서 거의 한 바퀴를 다 쓴다 |
| 흑월 `bgm_s1_heukwol_fight`(180초) · `_flood`(120초) | 6~8분 기준 | 새 길이에서 **그대로 맞는다**. 1·2단계 110~145초 동안 누름 → 밀어붙임 → 숨 → 몰아침이 한 바퀴 안에 들리고, 큰물 45~60초는 flood 반 바퀴다 |

## 3. 고친 것

### 1막: 2단계 = 같은 곡의 절정으로 건너뛰기
- 맺힘이 50%가 되는 순간, 곡을 바꾸지 않고 **같은 곡의 60.8초로 2초 교차**하며 건너뛴다.
- 60.8초는 절정 들머리이고, 4초 뒤 64.6초에 큰 북이 친다. 그래서 "절반을 깎았다 → 4초 뒤 음악이 터진다"가 된다.
- 절정은 115초까지 약 50초다. 2단계 45~60초와 거의 같은 길이다. 더 길어지면 60.8~142.65초를 반복한다(`phase2_loop_sec`).
- 1단계가 길어져 이미 60.8초를 지났으면 건너뛰지 않는다. 곡이 저절로 절정에 들어가 있다.
- 박자(0.5초 = 120 BPM)는 재서 맞췄다. 교차 2초는 4박이다.

### 2·3막: 임시 보스 곡을 2분으로 다시 만듦
- 1단계 `bgm_<지역>_boss` 120초는 다음 순서다: 시작 5초 → 차오름 5~35초 → **절정 35~80초** → 숨 80~90초 → 몰아침 90~120초.
  - 2막(1단계 60~75초)은 절정 한가운데에서 2단계로 넘어간다.
  - 3막(75~90초)은 절정 끝이나 숨 즈음에서 넘어가 자연스럽다.
- 2단계 `bgm_<지역>_boss_p2` 120초는 처음부터 거세다. 앞 절반과 뒤 절반의 가락이 다르다. 75~90초가 한 바퀴 안에 들어간다.
- 진짜 곡(AI 음악)이 오면 같은 이름으로 바뀐다. 그때도 **"2분 반복, 처음 5초 안에 장단이 들어옴, 절정은 35~80초쯤"**을 지시문에 적는다.

### 모든 보스: 넘어가는 규칙
| 키 | 값 | 왜 |
|---|---|---|
| `phase2_at_maedhim_frac` | 0.5 | 기획 확정 |
| `phase2_crossfade_sec` | 3.0 → **2.0** | 1막 건너뛰기를 4박에 맞춤. 다른 막도 같은 값으로 둔다 |
| `phase2_min_after_start_sec` | **20** (새) | 센 무기·도술로 맺힘이 빨리 깎여도 싸움 시작 20초 뒤에 넘어간다. 1단계의 차오름을 듣게 한다 |
| 처결(무릎) | 지금 규칙(`to_finish` 0.3초) | 그대로 둔다. 2단계 교차 중에 무릎이 와도 처결 곡이 바로 덮는다 |
| B-04 흑월 1차 | 보스 층 안 씀 → combat | 절반에서 물러나는 짧은 만남이다. 보스 곡이 시작만 하다 끊기지 않게 한다 |
| 쓰러진 뒤 다시 | 1단계 처음부터 | 같은 싸움을 다시 시작하는 것이니 곡도 처음부터 |

```csharp
// BgmPlayer 보스 층(제안). 지역 표에 phase2_seek_sec 가 있으면 곡을 바꾸지 않고 건너뛴다
// (왜) 1막 오너 곡은 절정이 64.6초에 있어, 1단계(45~60초)만으로는 절정을 못 듣는다
if (!phase2 && boss.Ratio <= 0.5f && fightT >= 20f) {
    phase2 = true;
    if (R.phase2_seek_sec > 0f) { if (src.time < R.phase2_seek_sec) CrossSeek(R.phase2_seek_sec, 2f); loopFrom = R.phase2_loop_sec[0]; }
    else Switch(Load("bgm_" + region + "_boss_p2"), "boss_p2", true, 2f);
}
// loopFrom: 곡 끝에 닿으면 0초가 아니라 loopFrom 으로(같은 소스 두 개로 1초 교차)
```
