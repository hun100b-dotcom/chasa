# P1-032 Higgsfield 프롬프트 가이드 (MCP 연결 후 사용, 현재 보류)
상태: **보류 — MCP 연결 후 진행**(오너 결정 2026-10-24). 지금은 가이드만 정리.

## 철칙
1. **작품명·캐릭터명·회사명 절대 금지**(IP-SAFETY). 팔레트 코드, 미술 사조, 전통 도상 이름으로만 지시.
2. 실루엣 먼저, 디테일은 나중: 검은 실루엣 합격 → 컬러 → 질감 순서로 3회 생성.
3. 생성물은 채팅에 붙이지 않고 `assets/`에 파일로 저장(비용 방어 룰).

## 허용 용어 / 금지 용어
- 허용: 흑립, 도포, 철삭, 단청, 탱화, 한지, 서낭당, 테네브리즘, 림 라이트, 낮은 키 라이팅
- 금지: 특정 영화·게임·만화 제목, "OO 스타일", 일본 사신 도상(낫·후드·해골)

## 공통 프롬프트 뼈대
`[대상], [실루엣 핵심 3개], 남청색 환경광(#16213E), 어두운 심연 배경(#0F1729), 포인트색 [토큰], 림 라이트, 낮은 키 라이팅, 한지 질감, 쿼터뷰 탑다운 45도, 단색 배경, 정면·측면·후면 3뷰`

## 예시
- 주인공: "흑립과 검은 도포를 입은 인물, 수평으로 넓은 챙, 흐르는 도포 자락, 허리의 붉은 띠(#E85C41), 손에서 늘어진 쇠사슬, 어깨 곁 청록 혼불(#5FE3C0)"
- 혼 4단계: 선명한 사람 형태(#BFE8FF) → 윤곽 번짐(#FFCC55) → 형태 붕괴(#FF6A3D) → 겹친 덩어리(#9A5CFF)
- 보스 원형: `BOSS-ARCHETYPES.md`의 실루엣 언어 문장을 그대로 사용

## 검수 흐름
생성 → 검은 칠 테스트(실루엣 읽힘) → IP 체크리스트(IP-SAFETY §4) → 팔레트 토큰 대조 → `assets/`에 저장 → 아트팀 승인.
