# P1-034 시야 축소 연출 스터디 (천도 캐스팅 중 시야 반경 60%)
목적: "마무리하는 순간이 가장 위험하다"를 화면이 직접 느끼게 한다. 규칙 수치는 COMBAT-SPEC/VISION이 SSOT, 여기는 시각 요구사항만.

## 요구사항
1. **어두워지는 방식**: 화면 가장자리부터 남청 `#0F1729`로 먹힌다(검정 아님). 중심 반경이 100% → 60%로 캐스팅 시작 0.25초 안에 줄고, 종료 시 0.15초에 복귀(들어갈 땐 천천히 조여 오고 나올 땐 빠르게 풀려야 "해방감"이 생김).
2. **경계 질감**: 부드러운 비네트 대신 먹이 번지는 가장자리(한지 위 먹 번짐 노이즈). 단청 문양이 가장자리에 은은히 비침(불투명 15% 이하).
3. **중심의 빛**: 캐스팅 중인 차사와 대상 혼 주변만 청록 `#5FE3C0` 글로우. 진행도는 글로우 반경이 아니라 혼의 윤곽이 선명해지는 정도로 표현(UI 막대 최소화).
4. **위험 신호**: 시야 밖에서 접근하는 적은 가장자리에 **붉은 `#E85C41` 맥박**으로 방향만 알린다. 모습은 안 보여야 함(축소의 의미).
5. **보스 천도(2.0초)**: 같은 연출이되 가장자리 문양이 하나 더 켜진다(보스전은 더 위험하다는 시각 구분).
6. **기억색 테두리**: 천도 성공 순간 보라 `#C9B0FF` 테두리가 0.3초 번쩍. 파혼은 이 연출 없음 → 파혼=이야기 없음을 색으로 대비.
7. **접근성**: 모바일 소형 화면에서도 60%가 읽히도록 하한(최소 반경)을 둔다. 깜빡임 주파수 3Hz 이하(광과민 안전).

## 구현 메모(코드팀 URP 이식용)
- 풀스크린 셰이더 한 장: 입력 = 중심 좌표, 반경, 경계 두께, 노이즈 텍스처, 방향 펄스 배열.
- 값은 config 한 곳에 모을 것. 아트팀 초기 제안값: 반경 1.0→0.6, 진입 0.25s, 복귀 0.15s, 경계 두께 반경의 12%.
- 확정은 Unity 설치 후 실제 화면으로 튜닝(수치는 여기서 못 정함).

## 미결
- 가장자리 문양 에셋(단청) — Higgsfield/수작업 에셋 단계에서 제작
- 파혼 시 원념 얼룩과 겹칠 때 색 충돌 확인(보라 계열 중복)
