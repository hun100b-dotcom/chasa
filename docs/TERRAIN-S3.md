## 보스 11종 규칙
- 시즌 1·2와 같은 틀: 뼈 9개(Root/Hips/Chest/Head/UpperArm.L·R/Hand.L·R/Prop), 클립 10개(Idle·Windup·Attack·Hit1·Hit2·Stagger·Kneel·KneelHold·Tendo·Pahon), 60fps, 원점=바닥 한가운데, 정면=−Y.
- 모두 **백(魄)=몸**이라 시즌 2 혼 보스와 달리 눈에 불을 켜지 않는다(발광은 B-31 횃불·B-28/B-31 정도만). 보스 대사 0줄이라 입을 그리지 않는다. 글자 없음.
- 약점 소품은 `Prop` 뼈에 있다: B-21 뒤집힌 배와 물 실 / B-22 일곱 몸을 묶은 줄 고리 / B-23 사공의 배·바깥 실 / B-24 건너편 기수·두 진 / B-25 버팀목 셋·광부 열둘 / B-26 빈 돌 열 / B-27 바닥 글씨 획 / B-28 돌아가는 벼루 바닥(속 빈 틀) / B-29 사잣밥 상 / B-30 새끼줄 / B-31 일곱의 빛·여덟째(개똥이)·보릿단.
- 크기: B-23 4.4 m(마당 반경 20), B-26 3.0 m, 나머지 사람형 1.35~2.4 m. 삼각형 710~2,240.

## 마당(`s3_arenas.json`)
- `at`=월드 중심, `R`=반경(기획 표). 파일 안 윗면 높이 0, 아래 0.6 m 치마(위층 지형 울퉁불퉁함을 가림). **지형과 같은 높이면 면이 깜빡이므로 `place_y_offset_m`=0.02만큼 올려 놓을 것.**
- 가장자리는 북쪽(+Y) 1.2 m 이하, 남쪽(−Y, 카메라 쪽) 절반 높이. 마당 안에 1.5 m 넘는 것은 없다(B-25 버팀목 2.6 m만 예외, 기획 지정).
- `events`: 눕히기/깨뜨리기/단계 때 코드가 놓을 소품 이름과 자리(마당 파일에는 넣지 않음). `mech`: 기획 수치(원 반경, 주기, 시한 등)를 코드가 읽을 값으로 그대로 옮김.
- **자리 확정(기획 10-25)**: B-23 (465,245) ⑦ 좌표계 / B-26 (140,500) 1막 필드 좌표(1막 흑월 1차 자리와 같음) / B-29 (415,901) ⑨ 좌표계. `s3_arenas.json`의 `at`에 반영했다.
- B-21과 B-31은 같은 물(소)이라 `at`이 같다. B-31은 B-21보다 더 깊은 층이므로 코드가 아래층 깊이를 따로 두어야 한다(8막 끝 전엔 닫힘).

## 윤리·기획 지킨 것
- 못 묻힌 몸은 **어두운 납작 윤곽(`s3_lying_shadow`)**으로만. 흙과 뼈는 단면으로. 훼손 묘사 없음, 아이의 죽음은 물건(보릿단)과 불빛으로만(`s3_barley_sheaf`).
- 열 시왕·재판·형벌 장면 없음. 특정 실제 사건을 가리키는 표지 없음.
- 열한 몸의 열두째 자리(`s3_linked_arms_eleven`)는 연한 윤곽 하나로 비워 두었다(8막까지 설명하지 않는다, F52).

## 장비 5등급 외형 (갓·도포·띠·신·노리개)
- 위치: `assets3d/gear/gear_{gat,dopo,tti,sin}_t1~t5.glb`, 노리개는 `gear_norigae_t1~t5_R/_L`(오른쪽·왼쪽 허리). 목록 `_manifest_gear.json`, 등급별 전신 5체 `previews/gear_tiers.png`.
- 등급: t1 흔한(미색) / t2 손본(청록) / t3 귀한(금빛) / t4 이름 있는(주홍) / t5 한 벌(혼불, 발광 조금).
- 방식: 주인공과 같은 뼈대 이름·같은 자리라 뼈 이름으로 조각을 갈아 끼운다(기본 모양의 갓·도포·띠·신·노리개는 숨김). 도포는 Hips·Spine·Chest·UpperArm.L/R 가중치, 신은 Foot.L/R, 갓은 Head, 띠·노리개는 Hips.
- 등급이 오를수록 재질·장식·색이 늘고, 갓끈 길이·띠 끝 가닥 수·신 코 높이·노리개 모양이 달라 색을 못 봐도 실루엣으로 구분된다.
- '이름 있는' 등급의 보스별 고유 물건(월화의 방울 등)은 이 위에 나중에 얹는다(여기는 주홍 외형만). 무기는 따로.
