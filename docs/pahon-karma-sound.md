# 파혼 손맛 · 업 배경층 · 원념 얼룩 — 소리 설계와 연결법 (코드팀용) — 기획·사운드, 2026-10-26 새벽

> 짝 문서: `docs/cast-danger-sound.md`(천도 중 위험). 천도는 "마무리가 가장 위험", 파혼은 "**당장은 가장 시원하고, 뒤에 남는 것이 귀를 탁하게**".
> 처결 필터: 둘 다 같은 크기로 매력 있게. 파혼의 손맛을 줄이지 않는다. 대신 업과 얼룩이 소리로 남는다.
> `Sfx.cs`·`JudgeSystem.cs`·`ZoneAmbient.cs`에는 손대지 않았다. 숫자는 Balance에 넣어 주면 기획이 조절한다.

## 1. 파혼 폭발의 손맛 — 넉백과 연쇄
| 때 | 소리 | 규칙 |
|---|---|---|
| 파혼 폭발(지금처럼) | `sfx.pahon.burst.<무기>` | 그대로. **땅을 울리는 저음은 이것 하나만** 갖는다 |
| 폭발에 밀려난 적 하나마다 | `sfx.pahon.knock` | 폭발 0.05초 뒤부터 0.03초 간격, 최대 4개, 하나마다 음높이 +4%(1.00·1.04·1.08·1.12). 좌우는 그 적의 화면 x |
| 함께 깨진 둘째·셋째·넷째 이상 | `sfx.pahon.chain.2` · `.3` · `.4` | 깨진 순서대로 0.16초 간격. 넷째부터는 `.4`만, 같은 소리 동시 최대 2개 |
| 셋 이상 함께 깨졌을 때 | `sfx.pahon.cascade` | 마지막 연쇄 0.15초 뒤 한 번. 부서진 조각 비 + 엽전 짤랑 |

**왜 이렇게 나눴나.** 폭발 소리를 여러 번 겹치면 저음이 쌓여 뭉개지고, 소리가 찢어진다(클리핑). 그래서 연쇄 소리는 250Hz 아래가 비어 있고, 한 칸마다 온음씩 높아진다. 겹치면 "쾅 — 쨍 쨍 쨍 차르르"로 계단처럼 올라가 시원하다. 깨지는 두 음이 반음 차이인 "찜찜함"은 연쇄에도 남겨 두었다.

지금 잔넋 연쇄(`JudgeSystem.cs`의 `chained++` 자리)에 `.2`/`.3`/`.4`를 순서대로 붙이면 된다. 거센 혼 파혼(반경 4.5m, 잔넋을 함께 터뜨림)이 이 소리를 가장 많이 쓴다.

## 2. 업이 쌓일수록 탁해지는 배경층 (업 10 · 30 · 60)
구역 환경음(`ZoneAmbient`) **위에 겹쳐 까는** 아주 작은 반복음 셋이다. 구역이 바뀌어도 계속 깔린다(업은 차사에게 붙은 것).
| 업 | 겹치는 것 | 들리는 느낌 |
|---|---|---|
| 0~9 | 없음 | 맑음 |
| 10~29 | `amb.karma.1` | 귀를 기울여야 들리는 낮은 웅(55Hz 맥놀이) |
| 30~59 | + `amb.karma.2` | 반음 어긋난 드론이 천천히 비벼짐 + 가끔 먼 숨 |
| 60 이상 | + `amb.karma.3` + 구역 환경음 전체에 저역 통과 6kHz | 바닥이 지글거리고 울렁임, 맑은 높은 소리(새·풀벌레)가 사라짐 |

- 단계가 오를 때 **8초**에 걸쳐 천천히 키운다(갑자기 바뀌면 '벌'처럼 들린다. 알아채지 못하게 스며야 한다). 내려갈 때(천도로 업 −1)도 8초.
- 음량은 파일에 맞춰 두었으니 1.0. 겹친 소리의 크기는 대략 −46 / −40 / −36 LUFS로, 구역 환경음(−36 안팎)보다 늘 작다.
- **비 오는 밤**(`weather.Fx.HideKarma`)에는 업 숫자를 가리는 것과 같이 이 층도 빗소리에 묻히게 0.5배로 낮춘다.
- 천도 시전 중 먹먹함(저역 통과 1.2kHz)은 이 층에도 그대로 걸린다(건너뛰지 않음).
- 서사 쪽 "업 10 이상이면 개가 짖는다"는 그대로 두고, 이 층과 함께 들리게 둔다.

## 3. 원념 얼룩
| 때 | 소리 | 규칙 |
|---|---|---|
| 얼룩이 생김(폭발 0.4초 뒤) | `sfx.stain.form` | |
| 얼룩 곁 | `amb.stain.near` | 얼룩마다 3D 반복음(spatialBlend 1, 최소 1m · 최대 8m, Logarithmic). 동시 최대 4개(가까운 순). 사라질 때 1초 페이드 |
| 얼룩 위를 걸음 | `sfx.stain.step` | `Sfx.PlayStep`에서 차사가 얼룩 반경 안이면 재질 발소리 **대신** 이것. 느려진 걸음(−20%)마다 |
| 얼룩 셋이 겹침 → 사나운 적 | `sfx.stain.overlap` | 소환 직전 한 번. 먹먹함을 건너뜀(bypass) |
| 얼룩이 마름(15초 끝) | `sfx.stain.fade` | |

## 4. Balance 상수 제안
`PAHON_KNOCK_SFX_MAX = 4`, `PAHON_KNOCK_SFX_GAP = 0.03`, `PAHON_KNOCK_PITCH_STEP = 0.04`, `PAHON_CHAIN_SFX_GAP = 0.16`, `PAHON_CASCADE_MIN = 3`, `KARMA_LAYER_FADE = 8`, `KARMA_LAYER_RAIN_MULT = 0.5`, `KARMA_T3_AMB_LP = 6000`, `STAIN_LOOP_MAX = 4`, `STAIN_LOOP_MAX_DIST = 8`.

## 5. 확인 방법(QA)
- 잔넋 넷을 끼고 파혼했을 때 "쾅 — 쨍 쨍 쨍 차르르"가 뭉개지지 않고 하나하나 들리는가. 찢어짐(클리핑)이 없는가.
- 업 0과 업 60의 같은 구역을 번갈아 들었을 때 "뭔가 탁하다"고 느끼지만, 업 10에서는 처음 하는 사람이 알아채지 못하는가(스며야 맞다).
- 미리 듣기 페이지의 시연 두 개(파혼 연쇄, 업 단계 6초씩)를 참고.
