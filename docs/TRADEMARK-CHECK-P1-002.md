- 조회어: 차사 / 車士 / 差使 / CHASA. (KIPRIS는 한자를 한글 독음으로 바꿔 검색해서 車士·差使 결과는 "차사"와 같은 집합)

### 9·41류 416건 전체 확인(보고 part 2) 추가 발견
- 416건 중 "차사" 단어 상표는 위 2건(둘 다 포기)뿐. 나머지는 차·참·차일드·차세대 등 무관한 이름.
- 🟡 **단음절 상표 "차"(등록번호 1326513, 9·41류 포함 다수 류 등록)**가 살아 있다. "차사"와 첫 글자가 같은 짧은 상표라 심사에서 유사 여부가 쟁점이 될 수 있다 → 변리사 확인 항목에 추가.

### 주의할 것
1. **영혼차사(39류)**: 저승사자 소재일 가능성. 류가 다르고(여행업) 이름도 다르지만, 같은 소재라 심사·분쟁 가능성을 **출원 전 변리사 확인** 권장.
2. 이 조회는 **국내 상표만**. 해외(WIPO 등) CHASA 조회는 안 함 → 해외 출시 전 별도 필요.
3. 판단 기준: 정확히 같은 이름 없음. "유사" 판단(발음·외관·의미)은 심사관·변리사의 영역이라 최종 확정이 아님.
4. 상표 **출원**은 오너 결정 + 변리사 확인 뒤(Phase 2 백로그, IP-SAFETY §5).
