# 업 칸 들어섬·나옴 소리 + 업 60 바탕 소리 (기획·사운드, 2026-10-26 KST)

> 근거: `planning/balance/karma-s1-check.md` §2(업 칸 손), 칸 이름은 서사팀 `docs/narrative/karma_tier_texts.json`.
> 파일: `Resources/Audio/Sfx/<id의 점을 밑줄로>.wav`. 크기는 파일에 맞춰 두었다.
> `JudgeSystem.cs`·`ZoneAmbient.cs`·`Sfx.cs`는 코드팀 파일이라 아래는 붙일 자리 제안이다.

## 1. 바람: "벌"이 아니라 "다른 길"

업 칸에 들어서면 새 손이 생긴다(10 미리 보임, 30 연쇄 파혼, 60 빛 없는 넋). 벌(귀 닫힘·넋 −10%·결말 A 막힘)은 따로 있고, 이미 다른 장치가 맡는다. 그래서 이 소리는 **새 길이 열렸다**만 말한다.

- **쓰지 않는 것**: 내려가는 반음, 버저처럼 거친 소리, 둔탁하게 막히는 소리, 지글거리는 잡음. 모두 "실패·오염"으로 들린다.
- **들어섬 = 열림**: 낮은 숨이 차오르고, 바탕음 위에 **완전5도**(도-솔처럼 비어 있고 넓은 음정)가 피어난다.
- **나옴 = 평온한 닫힘**: 5도가 먼저 사라지고 바탕음 하나만 남아 내쉬는 숨과 함께 가라앉는다. 음이 떨어지지 않는다. "원래 길로 돌아왔다"이지 "잃었다"가 아니다. 들어섬보다 4~5 dB 작다.
- **칸이 깊을수록 낮다**: 물든 눈 D4 → 잇단 사슬 A3 → 빛 없는 길 D3(징은 D2). "더 나쁜 길"이 아니라 "더 깊은 길"이다. 모든 음은 D 5음계(D·E·F#·A·B) 안이라 서로 어긋나지 않는다.

| `sfx.karma.tier.60.exit` | 업이 60 아래로 | 징을 세게 치지 않고 부풀기만 → 굴 바람이 닫힘 → D 한 음(1.8초) | 어둠에서 나옴 |

## 3. 업 60 바탕 소리 `amb.karma.3` (다시 만듦)

- **옛 판**: 지글거리는 잡음 + 느린 울렁임 + 먼 파혼 깨지는 메아리. "공기가 탁함"이라 벌·오염으로 들렸다.
- **새 판(28초 반복)**: 아주 낮은 D2-A2-D3 5도가 7초 숨으로 천천히 부푼다. 그 위에 긴 굴 속을 지나는 어두운 바람이 있다. 9초쯤마다 먼 징이 웅 울리고, 아주 가끔 먼 사슬 고리 하나가 울린다(잇단 사슬과 이어짐). 2 kHz 위는 걷어 어둡다. 잡음·깨지는 소리는 없다.
- 들어섬 소리와 같은 D-A 5도라서, 들어선 뒤 바탕이 스며들면 "그 길 위에 있다"가 계속 들린다.
- 최고 −24 dBFS(옛 판 −18). 지글거림이 빠져 소리가 꽉 차므로 더 작게 둬도 들린다.

### 겹침 규칙을 바꾼다

| 업 | 지금(docs/pahon-karma-sound.md) | 바꿀 것 |
|---|---|---|
| 10~29 | `amb.karma.1` | 그대로 |
| 30~59 | 1 + `amb.karma.2` | 그대로 |
| 60 이상 | 1 + 2 + 3 + 환경음 6 kHz 저역 통과 | **1 + 3**. `amb.karma.2`는 8초에 걸쳐 뺀다. 2의 반음 비빔(D·D#)이 3의 D-A 5도와 부딪혀 다시 "탁함"으로 들리기 때문이다. 1(A1 55 Hz)은 5도와 어울리니 남긴다. 6 kHz 저역 통과(귀 닫힘 벌)는 그대로 |

## 4. 붙일 자리 (제안)

```csharp
// JudgeSystem: 업이 바뀌는 모든 곳(파혼·천도 감쇠·보스 파혼 +3·잔넋 +0.5 모음) 뒤에서 한 번 부른다
// (왜) 업은 여러 군데서 바뀐다. 칸 비교를 한 곳에 모아야 소리가 빠지거나 두 번 나지 않는다
int lastTier;   // 지난번 업 칸(0·1·2·3 = CoreRules.KarmaTier)
void OnKarmaChanged()
{
    int tier = CoreRules.KarmaTier(ledger.Karma);
    if (tier == lastTier) return;
    string[] ids = { null, "10", "30", "60" };
    if (tier > lastTier)
        Sfx.PlayLater("sfx.karma.tier." + ids[tier] + ".enter", tier == 3 ? 0.6f : 0.5f);   // 여러 칸을 한꺼번에 넘으면(보스 파혼) 가장 높은 칸 하나만
    else
        Sfx.PlayLater("sfx.karma.tier." + ids[lastTier] + ".exit", 1.2f);                  // 천도 보상 소리(혼불·기억)가 끝난 뒤
    lastTier = tier;
}
```

- 늦춰 트는 까닭: 들어섬은 파혼 폭발 바로 뒤에 오면 파혼 손맛을 덮는다(0.5초 뒤). 나옴은 천도 보상 순서(`audio_mix.json` → `sequence`, 품계 인 2.0초)와 겹치지 않게 1.2초 뒤에 둔다. 같은 순간 품계 인이 울리면 나옴을 2.8초로 미룬다.
- 칸 글(`karma_tier_texts.json`)이 화면에 뜨는 때와 들어섬 소리를 같이 맞춘다.
- 불러오기·막 넘어가기처럼 업이 "처음 정해질" 때는 소리 없이 `lastTier`만 맞춘다(바탕 소리만 조용히 깐다).
- 업 칸을 짧은 사이에 오르내리면(30에서 파혼 → 천도 → 파혼) 같은 칸의 들어섬·나옴은 **6초에 한 번**만 낸다.
- 비 오는 밤(`weather.Fx.HideKarma`)에는 업 숫자를 가리므로 들어섬·나옴도 내지 않는다. 바탕 소리는 지금 규칙대로 0.5배.
- 이 소리들은 천도 먹먹 필터를 건너뛰지 않는다(`bypass_cast` 없음). 전투 경고가 아니기 때문이다.
