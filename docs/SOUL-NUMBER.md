# ④ 쇳골 숫자 혼 외형 (아트 → 기획·코드)

근거: 기획 부록 F "숫자 혼: 명부에 번호로만 적혔다(인 없음). 천도 캐스팅 +0.5초, 넋 ×1.3. B-08 천도 뒤 이름을 되찾아 +0.25초". ④ 광부촌 15%·큰 갱도 25%·무너진 막장 50~70%.

## 모델 8종 (`assets3d/souls/`, Unity `Resources/Models/Soul/`에 복사)
`soul_{fresh,day,old,lump}_number.glb` — 이름 없는 번호 상태 / `soul_{...}_number_named.glb` — B-08 천도 뒤 이름을 되찾은 상태.
- **광부 차림이되 광부 혼과 갈린다.** 쇳골 광부 혼(`_soegol`)은 등불 켠 투구 + 곡괭이. 숫자 혼은 **불 꺼진 검은 투구**(등불 자리가 비어 있음) + **목에 쇠고리** + **가슴 아래까지 늘어진 큰 나무 번호 목패**(0.3×0.42 m). 곡괭이는 없다.
- 번호는 글자가 아니라 목패에 새긴 홈 줄 셋으로만 읽힌다(그림에 글자 없음 규칙). 목패는 일반 혼 위에 무릎까지 늘어져 쿼터뷰에서 실루엣이 달라진다.
- 이름 되찾음(`_named`): 같은 목패 옆에 **발광 이름 쪽지**(미색, 글자 없음)가 실로 매달린다. 코드는 B-08 천도 플래그에 따라 `_number` ↔ `_number_named`를 바꿔 끼우면 된다(뼈·재질 구조 동일).
- 기본 혼 몸(색·세기 = 나이)은 그대로. 주황 안 씀. 삼각형 ≤1300.
- 미리보기 `assets3d/previews/souls_number_50deg.png`(행: 기본 / 쇳골 광부 / 숫자 혼 / 이름 되찾은 숫자 혼, 열: 갓 죽은·해 넘긴·오래된·덩어리). 만든 스크립트 `tools/art3d/soul_variants.py`(region `number`, `number_named`).
