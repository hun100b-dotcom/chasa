# 처음 10분 소리 한 줄 점검 + 믹스 다듬기 (기획·사운드, 2026-10-26 KST)

> 근거: `planning/controls/first-5-minutes.md` v2(0:00~10:00 흐름), 지금 코드의 크기 규칙.
> - 효과음: 1.0 × 설정 1.0
> - 발소리: 0.45
> - BGM: 탐험 0.5 / 전투·처결 0.45 × 설정 0.8
> - 구역 바탕: 0.6
>
> 측정 방법: 실제 소리 파일을 장면별 시간표대로 섞는 시뮬레이터 `tools/mix_first10_sim.py`로 잰다. 중요한 소리(대기 똑딱·마지막 경고·위험 예고·무릎)가 울리는 동안, 250 Hz~8 kHz를 다섯 대역으로 나눈다. 가장 잘 들리는 대역에서 이 소리가 나머지 모든 소리보다 몇 dB 위에 있는지 잰다. **3 dB 미만이면 "묻힘"**이다.

## 1. 장면별 소리 시간표 (요약)

| 시각 | 장면 | 1초 안에 몰리는 소리 |
|---|---|---|
| 0:25 | 걷기 | 발소리(초당 4), 밤 곡, 마을 밤 바탕 — 가장 조용(최고 −11.7 dBFS) |
| 1:00~1:30 | 첫 혼 싸움 → 첫 천도 | 타격 3연타 + 예고 + 회피 / 무릎 + 처결 카드 + 처결 곡 |
| 2:40~2:55 | 둘러싸임: 하나 꿇고(대기 10초) 둘이 공격, 그 사이 천도 | 타격·예고·맞음 + **대기 똑딱** + 천도 시전·경고 |
| 5:00 | **박돌쇠 천도** + 품계 2 | 천도 끝 + 혼불 + 기억 + 품계 인 + 넋 막대 → **1초에 7개** |
| 5:00 | 박돌쇠 파혼 + 품계 2 | 파혼 + 엽전 튐 + 엽전 모임 + 품계 인 + 막대 → 1초에 5개 |
| 7:00 | 거센 혼 + 잔넋 셋, 대기 7초 중 공격 | 거센 혼 예고 둘 + 타격 + 잔넋 예고 + 대기 똑딱 + 파혼·드롭 → **1초에 10개** |

모든 장면이 0 dBFS 아래다(가장 큰 것 −2.2). 소리가 터져 깨지는 곳은 없다. 문제는 **묻힘**이다.

## 2. 찾은 문제

| # | 문제 | 고치기 전 | 원인 |
|---|---|---|---|
| 1 | **갓 죽은 혼 대기 똑딱이 거의 안 들림** | 둘러싸임 −21 dB, 박돌쇠 −18 dB, 파혼 판 −15 dB | 소리의 힘이 60 Hz 밑에 몰려 있었다(심장 '두근'). 쓸 만한 대역에서는 전투 곡·처결 종·마을 바탕보다 한참 작다. **폰 스피커에서는 아예 안 나온다** |
| 2 | 해 넘긴 혼 똑딱·마지막 1.5초 경고가 거센 혼 싸움에서 아슬아슬 | −0.1 dB / −3.4 dB | 전투 곡 + 잔넋·타격이 같은 대역(500 Hz~2 kHz) |
| 3 | **천도 중 경고음이 먹먹 필터에 깎임** | 잔넋 경고 −14 dB, 넋두리 −8 dB, 바람(지금 친다) −6 dB, 꿇은 동안 예고 −3 dB | `sfx_files.json`에 `bypass_cast_filter: true`인 소리가 84개 있다. 그런데 `Sfx.cs`는 이 값을 읽지 않고 **`sfx.enemy.telegraph` 하나만** 필터를 건너뛴다. (내가 처음 10분 연결표에 "이미 읽는다"고 쓴 것은 틀렸다. 고쳐 두었다) |
| 4 | **박돌쇠 처결 끝 1초에 보상 소리 7개** | 천도 끝·혼불·기억·품계 인·막대가 0.0~1.1초에 겹침 | 품계 인(가장 중요한 첫 성장)이 천도 끝 꼬리(2.2초)에 묻힌다 |
| 5 | `data/audio_mix.json`(믹스 기준표)을 코드가 읽지 않음 | — | BgmPlayer에 0.5/0.45가 직접 적혀 있다. 지금은 표를 고쳐도 게임이 바뀌지 않는다 |

## 3. 고친 것 (소리 파일, 기획·사운드)

| 소리 | 고침 |
|---|---|
| `sfx.wait.tick.fresh` | 몸통을 500~900 Hz '둔한 톡' 두 번으로 옮겼다. 낮은 둥은 받침으로만 남겼다. 최고 −16 → **−11 dBFS**. 길이(0.29초)와 '두-근' 박자는 그대로다 |
| `sfx.wait.tick.year`·`old`·`numbered` | +2 dB(−14 · −13 · −14) |
| `sfx.wait.final` | −14 → **−10 dBFS** |

## 4. 코드팀에 부탁 (제안)

1. **필터 건너뛰기 연결**: `Sfx.PlayInternal`의 아래 줄을 바꾼다.
   ```csharp
   // 지금
   v.bypassListenerEffects = id == "sfx.enemy.telegraph";
   // 바꿀 것: sfx_files.json 의 bypass_cast_filter 를 읽어 둔 표
   v.bypassListenerEffects = bypassCast.Contains(id);
   ```
   (왜) 천도 중에야말로 경고가 또렷해야 한다. 지금은 잔넋 경고가 14 dB 깎인다.
2. **대기 똑딱 더킹(잠깐 낮추기)**: 14 m 안에 처결 대기 혼이 있는 동안 **음악만 0.7배**로 낮춘다(0.2초에 내리고 0.5초에 올림). 효과음·예고음은 그대로 둔다. `audio_mix.json` → `duck.wait_tick`.
3. **보상 소리 순서 벌리기**(`audio_mix.json` → `sequence`):
   - 천도 끝 0.0 → 혼불 0.5 → 기억 1.2 → **품계 인 2.0** → 막대 2.6초
   - 파혼 0.0 → 엽전 튐 0.05 → 모임 0.6 → **품계 인 1.4** → 막대 2.0초
4. 처결 대기 똑딱을 **남은 초 기준**으로 바꾸고, 마지막 1.5초에는 똑딱을 멈춘다(`docs/move-sound-sync.md` 3절, 이미 전달함). 위 숫자들은 이 규칙을 넣은 상태로 잰 것이다.
5. (나중에) `audio_mix.json`의 `bus`·`duck` 값을 BgmPlayer·Sfx가 읽게 바꾼다. 그래야 귀로 맞출 때 표 하나만 고치면 된다.

## 5. 고친 뒤 (3절 파일 + 4절 1~4 제안을 넣었을 때)

| 장면 | 고치기 전 | 고친 뒤 |
|---|---|---|
| 둘러싸임 대기 똑딱 | 21개 모두 묻힘, 평균 −21 dB | 14개 중 7개만 **0~+3 dB**(타격과 정확히 겹친 것). 나머지는 또렷 |
| 박돌쇠 천도 | 똑딱 묻힘 −18 dB, 1초에 7개 | 묻힘 0, 1초에 **3개** |
| 박돌쇠 파혼 | 똑딱 −15 dB, 1초에 5개 | 묻힘 0, 1초에 3개 |
| 거센 혼 대기 | 해 넘긴 똑딱 −0.1 · 마지막 경고 −3.4 dB | 똑딱 또렷, 마지막 경고 **+1.4 dB** |
| 천도 중 경고 | 최대 −14 dB 깎임 | 0(필터를 건너뜀) |

- 남은 약점: 둘러싸였을 때 타격음과 **같은 순간**에 난 똑딱은 아직 0~3 dB이다. 들리기는 하지만 약하다.
- 타격감을 깎지 않으려고 타격음은 낮추지 않았다. PC에서 들어 보고 더 필요하면 대기 중 타격 0.85배를 검토한다.
