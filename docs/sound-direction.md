# 차사 사운드·음악 방향 (기획, 2026-10-24 · 10-25 Gemini 음악 확정 반영)

> 코드팀 F3(임시음) 바로 착수용. 2026-10-24 개정: 오픈월드 전환. 낮/밤은 남지만 건너뛰기 없이 자연스럽게 흐르는 월드 시계. 그래서 '판 진행률' 규칙을 월드 시계 시각 + 지역 위험도·보스 근접 기준으로 바꿈. 합성 값은 같은 폴더 `sfx_synth.json`.
> 원칙: **소리는 선택을 돕는다.** 천도/파혼 순간이 가장 잘 들려야 하고, 위험(적 예고)은 화면을 안 봐도 들려야 한다.

## 0. 세 가지 규칙
1. **처결 순간이 주인공.** 무릎 꿇음(kneel) 소리가 들리면 플레이어는 "지금 고를 때"임을 안다. 믹스 우선순위 1위.
2. **천도는 맑고 조용하게, 파혼은 크고 더럽게.** 천도 = 방울·숨·맑은 배음. 파혼 = 단2도(반음) 부딪힘이 섞인 폭발. 둘 다 쾌감은 있어야 한다(파혼이 "벌"처럼만 들리면 선택이 안 된다).
3. **천도 캐스팅 중엔 세상이 먹먹해진다.** 시야 60% 축소와 짝: 마스터(전체 소리)에 저역 통과 필터(높은 소리를 깎는 필터) 20kHz → 1.2kHz, 0.25초에 걸쳐. 단, **적 예고음은 필터를 건너뛴다**(위험은 들려야 함).

### 믹스 규칙
- 우선순위: kneel·tendo·pahon > telegraph > hit > hurt > footstep·amb.
- 같은 소리 동시 재생 최대 4개(넘으면 가장 오래된 것 끊기). 다수전에서 귀가 안 터지게.
- 타격음은 재생마다 음높이 ±6%, 크기 ±1.5dB 무작위. 같은 소리 반복 피로를 줄임.
- **타격음은 히트스톱 시작 프레임에 재생.** 멈춘 화면 + 소리 = 손맛. 끝난 뒤에 나면 늦게 느껴짐.
- 기준 크기(dBFS, 0이 최대): hit −9, heavy −6, kneel −8, tendo.done −7, pahon −4, telegraph −10, amb −24, footstep −20, ui −14.
- 소리 켜기/끄기 버튼 필수(설정에 저장).
- 폰: 파혼·heavy에 진동 짧게(30ms / 60ms).

## 2. 음악(BGM) 방향 — 국악 기반 어두운 오픈월드

**한 줄:** 망자를 씻어 보내는 굿 음악의 정서(시나위 — 정해진 선율 없이 악기들이 엇갈려 즉흥으로 우는 합주)를, 필드의 위험도에 맞춰 층으로 쌓는다.

### 악기 역할
| 악기 | 역할 |
|---|---|
| 아쟁(활로 긁는 저음 현) | 공포·긴장의 바닥. 길게 끄는 음 |
| 대금(큰 가로피리) | 숨소리 섞인 선율. 탐색·기억 장면 |
| 해금 | 혼의 울음. 이름 있는 혼, 보스 |
| 거문고 | 술대로 내려치는 타격음. 전투 강세 |
| 장구·북 | 장단(리듬). 전투 층 |
| 징 | 구간 전환, 처결, 위험 지역 진입 |
| 요령(무당 방울) | 천도·처결. 우리 무기(요령방울)와 같은 소리 계열로 통일 |

### 층 구조(상황에 따라 켜고 끄는 방식)
- **층 1 탐색:** 아쟁 드론 + 대금 띄엄띄엄. 거의 음악 같지 않게.
- **층 2 전투:** 적이 8m 안에 들어오면 장구 장단이 들어옴. 자진모리(빠른 12박)부터.
- **층 3 처결:** 무릎 꿇는 순간 장단이 멈추고 징 한 번 + 아쟁만 남음. 천도 중엔 이 상태 유지 → 끝나면 층 2로 복귀. (기둥 1: 마무리 순간이 가장 고요하고 가장 위험하다.)
- **월드 시계:** 낮은 탐색 층이 가볍고(대금 위주), 해가 지면 아쟁 드론이 깔림. 월드 시계가 동트기 전 시각(밤의 마지막 1/4)에 들면 장단이 휘모리(가장 빠른 장단)로, 아쟁 음높이 반음 올림. 혼이 가장 날뛰는 때라는 압박을 귀로.
- **위험도:** 지역 위험도(원념이 짙은 깊은 곳일수록 높음)가 오르면 장단이 자진모리 → 휘모리로 한 단계씩. 필드 보스 30m 안에 들어서면 보스 동기가 겹쳐 들어옴. 시계와 위험도 중 높은 쪽을 따름.
- **마을·서낭당(쉼터):** 진양조(가장 느린 장단) 수준의 느린 가야금·대금. 숨 돌리는 곳. 빠른 이동 지점 도착 때도 이 층으로 짧게 전환.
- **보스:** 해금 주선율 + 중모리(중간 빠르기). 보스마다 '한'을 나타내는 짧은 동기(2~4음) 하나씩 — 기억 조각 장면에서 같은 동기를 다시 씀.

### 피할 것
- 국악 + 전자음 댄스 퓨전, 사극 드라마풍 대편성 관현악. 우리 톤은 "작고 가까운 소리".
- AI 음악 생성 프롬프트에 다른 작품·OST·작곡가 이름 금지. 장단·악기·빠르기·분위기 단어로만 지시.

### 2-1. 최종 BGM = Gemini 음악 생성 (2026-10-25 오너 확정)
오너가 Gemini(구글 AI, 음악 모델 Lyria)로 직접 뽑아 보고 "쓸 만하다"고 결정. Suno 결제·코드 작곡 시험은 접음(비교표는 `ai-music-tools-and-prompts.md`에 참고용으로 남김).

**약관 확인 결과(2026-10-25)**
- 구글 서비스 약관(2026-07-30 시행): AI로 만든 콘텐츠는 "구글이 소유권을 주장하지 않음". 상업 이용 금지 조항 없음 → 게임에 넣어 팔 수 있음.
- 지킬 것 ①: **사람이 만든 것처럼 속이면 안 됨**(약관 금지 사항) → 크레딧에 "음악 일부 AI 생성(Google Gemini)" 표기, 스팀 등록 때 AI 사용 항목에 체크.
- 지킬 것 ②: 생성 AI 금지 정책 지키기(남의 곡 흉내, 실존 가수 목소리 등) → 지시문에 작품·OST·작곡가·가수 이름 금지(원래 규칙).
- 지킬 것 ③: 받은 곡을 다른 AI 학습에 쓰면 안 됨.
- 알아둘 것: 모든 곡에 들리지 않는 AI 표시(SynthID 워터마크)가 들어감. 쓰는 데 문제 없음. AI만으로 만든 곡은 저작권 등록이 어려울 수 있음(남이 같은 곡을 따로 뽑아 쓰는 걸 막기 어려움).

**제약과 대응**
| 제약 | 대응 |
|---|---|
| 받기는 MP3(또는 MP4)만, 악기별 분리 없음 | 층을 **따로 뽑고**, 겹쳐 틀지 않고 1~2초 교차로 넘김. 전투 층의 타악만 겹치고 싶으면 무료 분리 프로그램(Demucs, MIT 사용 허락)으로 우리가 분리 |
| 무료판은 짧은 곡(약 30초~1분), 3분 긴 곡은 유료(Google AI Plus 이상) | 첫 곡은 짧은 곡을 반복으로 시작. 반복이 귀에 거슬리면 그때 유료 검토 |
| 같은 곡 일부만 고치기 안 됨 | 마음에 안 들면 같은 지시문으로 다시 뽑기(3~4번) |
| 박자·음 높이가 층마다 어긋날 수 있음 | 지시문에 빠르기(72)·음 높이 중심(D)·음계(계면조)를 모두 같게 고정 |

**만드는 순서(곡 하나당)**
1. 오너가 Gemini에 지시문을 붙여 넣고 3~4번 뽑아 마음에 드는 것을 MP3로 받아 채팅에 올림(오너가 직접 하겠다고 함).
2. 팀이 루프 지점 맞추기(장단 한 바퀴 단위로 자르고 끝 0.5초 겹쳐 이음), 음량 맞추기(탐색 −20 LUFS, 전투 −16 LUFS — 소리 크기 기준 단위).
3. `data/audio_credits.json` 기록: tool=Google Gemini(Lyria), 생성일, 지시문 전문, 계정 요금제, "AI 생성" 표시.

### 2-2. 첫 곡 계획 — 「솔고개 필드」 (1막 첫 지역)
| 층 | 내용 | 켜지는 때 |
|---|---|---|
| 탐색-낮 | 대금 띄엄띄엄 + 가야금 몇 음, 바람 같은 여백 | 기본 |
| 탐색-밤 | 아쟁 드론 앞에, 대금 낮게 | 월드 시계 해 진 뒤(해질녘 8초 교차) |
| 전투 | 장구 자진모리 + 거문고 강세 + 해금 | 적 8 m 안 |
| 처결 | 장단 멈춤, 징 한 번 + 아쟁 긴 음 + 요령 몇 번(약 30초, 반복 안 함) | 무릎 꿇는 순간~천도 끝 |
네 층 모두 72 BPM(전투는 두 배 144로 박을 맞춤)·D 중심·계면조로 고정. 지시문 원문은 오너용 페이지(복사 버튼)와 `ai-music-tools-and-prompts.md` 6절.
완료 기준: 시연판에서 걷기 → 적 접근 → 처결까지 음악이 끊긴 느낌 없이 바뀌면 합격. 다음 곡: 마을 쉼터(진양조) → 첫 보스 동기.

## 4. 코드팀 F3 작업 순서(제안)
1. `SfxPlayer`(id로 재생, 음높이·크기 무작위, 동시 재생 제한, 우선순위) + 마스터 저역 필터(천도 먹먹함) + 소리 켜기/끄기.
2. `sfx_synth.json`의 P0 8개를 코드 합성으로 만들기(Unity `AudioClip.Create`로 PCM 생성). 손맛 값 표(feel.json)의 `sfx` 칸이 이 id를 가리킴.
3. BGM 층 재생기(탐색·전투·처결 층을 박에 맞춰 1~2초 교차로 넘기기)는 F3 끝에 넣음. 첫 곡(2-2절) 파일이 나오기 전엔 `amb.field` + 처결 시 110Hz 드론으로 대신.
4. 확인: 소리는 헤드리스로 못 들으니 ①id별 재생 로그 = 사건 로그 일치 테스트 ②파형 길이·최대 크기 검사(−1dBFS 넘으면 실패) ③오너 PC에서 체감 한 줄.
5. 이후 Kenney·Freesound CC0 샘플로 같은 id를 교체(id 유지, 파일만 바꿈).

## 시즌2 저승 ⑦~⑩ 사운드 방향 (2026-10-25 밤, season2_outline·npc_act4·memories_act4 기준)

### 한 줄
**"모두가 나를 보는데 아무도 말을 걸지 않는다"를 귀로.** 소리는 많지만 산 것이 없다.

### 네 가지 규칙
1. **산 것의 소리가 없다.** 새·벌레·개구리·개·닭은 쓰지 않는다. 이승 환경음에서 '살아 있음'을 내던 층을 빼고, 물·종이·먹·쇠·숨으로 채운다.
2. **말은 들리되 뜻은 안 들린다.** 줄 선 혼과 서리는 저희끼리 웅얼거린다. 숨을 많이 섞고 1.1~1.6kHz 위를 깎아 자음을 지운다(차사에게 하는 말이 아니므로).
3. **물이 제대로 흐르지 않는다.** 하류가 깨진 가루로 막혀 있다(F12). 그래서 고이고(갈대늪), 끈적하고(먹물 여울), 짓눌려 운다(둑·물막이 바닥).
4. **울림은 길고 어둡게.** 이승보다 잔향을 1.5배 길게 하고, 4kHz 위를 깎는다.

### 지역별

|---|---|---|

## 시즌3 「백의 밤」 사운드 방향 (2026-10-25 밤, season3_outline·memories_s3 기준)

### 한 줄
**"물이 빠진 바닥에서, 말 없는 몸을 만난다"를 귀로.** 위층 소리는 머리 위에서 먹먹하게만 새어 들고, 아래층은 물방울·젖은 흙·갇힌 공기로 채운다.

### 네 가지 규칙
1. **아래층은 물이 빠진 바닥이다.** 뚝뚝 떨어지는 물, 찌걱이는 뻘, 흙알갱이 사르르. 위층 환경음은 380Hz 아래만 남겨(머리 위 먹먹함) 아주 작게 섞는다.
2. **백(몸)은 말하지 않는다.** 웅얼거림도 없다. 몸의 소리(흙이 밀림·무릎·천 스침)와 '원념의 실'의 가늘고 팽팽한 울림만 쓴다.
3. **물 차오름은 귀로 먼저 안다.** 새벽 30초 전 경고는 멀리서 차오르는 우르르(천도·눕히기 중에도 들림), 2분 차오름 동안 물소리가 커진다. 떠밀려 올라가는 소리는 무섭지 않게(벌 없음).
4. **눕히기는 내려앉음, 깨뜨리기는 터짐.** 눕히기 = 흙이 숨을 내쉬듯 가라앉고 맑은 방울 하나가 위로. 깨뜨리기 = 흙·물째 둔하게 터지고 반음 부딪는 쇳소리(시즌1 파혼과 같은 찜찜함).
