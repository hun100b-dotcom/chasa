## 2. 고친 것
- **B12-RISE 새 컷(1.5초, 대사 0):** 처결 대기가 끝나면 새벽빛이 걷히고 흑월이 사슬을 다시 감아 쥔다. 다시 맺힘 0이면 KNEEL을 **대사 없이** 다시(한마디는 한 번만). 대기 7초는 그대로(기둥 수치).
- **C-12A 떠남:** 눈밭을 떠돌던 혼 열둘이 흑월 뒤를 따라간다 — C-12B의 "혼 열둘이 떠돌던 자리가 비었다"와 짝(A판에서 열둘이 어떻게 됐는지 비어 있었음).
- **"이름이 들리지 않는다" 마침표:** 화면 글 규칙(마침표 없음)대로 1·2·3막·시즌 2 보스 전부 뺌.
