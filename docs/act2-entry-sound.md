# 2막 들어섬 + 장비 새 칸 열림 소리 (기획·사운드, 2026-10-26 KST)

> 근거: `planning/controls/act2-entry-10min.md` 1·2절 흐름표, `sound/act2-soundscape.md`.
> 파일: `Resources/Audio/Sfx/<id의 점을 밑줄로>.wav`. 크기는 파일에 맞춰 두었다.
> `JudgeSystem.cs`·`ZoneAmbient.cs`·`BgmPlayer.cs`·`Sfx.cs`는 코드팀 파일이라 아래는 붙일 자리 제안이다.

## 1. 바람

- **금줄 끊김**은 "막혔던 것이 풀림"이다. 무섭지 않고 시원해야 한다.
- **고개 넘음**은 "새 땅의 첫 숨"이다. 2막 첫 10분은 대개 아침이고, 산 사람의 때다. 그래서 넓고 밝게 둔다.
- 두 길(붉은재·쇳골)은 넘는 순간의 빛깔만 다르다. 바탕 한 겹(바람이 확 트임)은 같다.
- **장비 새 칸**은 품계 인(`sfx.rank.seal`, −8 dBFS)과 같은 크기의 "좋은 일"이다.

## 3. 소리 넘김 시간표 (③ 붉은재, ④ 쇳골도 같은 틀)

| 시각 | 그림 | 효과음 | 구역 바탕(ZoneAmbient) | 음악(BgmPlayer) |
|---|---|---|---|---|
| 0:00 | 금줄 한지가 끊겨 날림 | `sfx.geumjul.snap` | 1막 바탕 그대로 | 1막 곡을 2.5초 동안 **0.6배**로(끊김이 들리게) |
| 0:00~0:07 | 고개를 오름(금줄 40 m 앞 → 금줄) | — | 1막 바탕이 **거리로** 빠지기 시작 | 1막 곡도 같은 거리로 1 → 0.3 |

| 0:07~0:18 | 금줄 60 m 뒤까지 | `amb.geumjul.cut`(뒤에서 멀어짐) | 1막 0, 2막 1(100 m 다 넘김) | 2막 곡 |

### 붙일 자리 (제안)

```csharp
// ZoneAmbient: 금줄을 사이에 둔 100 m(금줄 40 m 앞 ~ 60 m 뒤)에서는 1막·2막 바탕을 '거리'로 섞는다
// (왜) 지금은 구역이 바뀌는 순간 4초 교차라 고개 한가운데서 소리가 뚝 바뀐다. 기획은 "고개 100 m에 걸쳐 빠짐"
float k = Mathf.InverseLerp(gateZ - 40f, gateZ + 60f, playerZ);   // 0 = 1막 쪽, 1 = 2막 쪽
act1Bed.volume = (1f - k) * baseVol;  act2Bed.volume = k * baseVol;

// BgmPlayer: 금줄을 넘는 순간(구역 이름 띠가 뜨는 프레임)
// (왜) 지역 키가 바뀌면 바로 4초 교차하는 지금 규칙이면, 2막 곡이 들어섬 소리와 겹쳐 둘 다 흐려진다
bgm.Duck(0f, 1.0f);                                  // 1막 곡 1초에 0으로
bgm.PlayRegionAfter("bulgeunjae", delay: 1.0f, fade: 3.0f);   // 들어섬 소리 1초 뒤 2막 곡

// JudgeSystem: 금줄 끊김
if (open && !snapPlayed && Vector3.Distance(player.Pos, gatePos) < 8f) { snapPlayed = true; Sfx.Play("sfx.geumjul.snap", gatePos); bgm.Duck(0.6f, 2.5f); }
```

- `snapPlayed`·들어섬 소리는 두 금줄을 합쳐 **한 번씩만** 낸다. 붉은재로 먼저 넘었다면, 나중에 쇳골 금줄 앞에 가면 끊김은 다시 들린다(그 금줄은 처음 보니까). 하지만 들어섬은 `sfx.region.enter.soegol`로 그 구역에서 한 번이다.
- 밤에 처음 넘어도 같은 소리를 쓴다. 피리는 밝지만 작고, 2막 밤 곡이 곧 덮는다.

## 4. 코드와 기획이 다른 곳 (확인 부탁)

`JudgeSystem` 948줄은 장비 새 칸(신·노리개 2)을 **2막 땅에 첫 발을 디딜 때** 연다. 흐름표(act2-entry-10min.md 1절)는 **첫 서낭당에서 쉴 때** 1초 연출로 연다.
- 서낭당에서 열면: 소리는 칸 연출과 같이 한 번이면 된다.
- 지금처럼 첫 발에 열면: 들어섬 소리·2막 곡과 같은 순간이 된다. 그러면 `sfx.equip.slot.open`을 **들어섬 소리 2.5초 뒤**로 미뤄야 셋이 겹치지 않는다.
- 기획 쪽이 맞다면 서낭당으로 옮기는 편이 소리로도 깔끔하다(새 규칙은 한 번에 하나).
