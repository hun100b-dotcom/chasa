## 기획에 되묻는 것(명세와 어긋나는 곳)
1. **정예 적 미니맵 점이 명세에 '주황'.** 주황은 파혼 전용이라 아이콘은 붉은 점+둘레 가시로 만들어 두었다(`icon_elite`). 명세 §2 표를 고쳐 주세요.
2. **미니맵 점 크기 제안:** 적 6→8, 혼 8→10, NPC 8→10(폰 200 px 지도는 ×1.2). 지금 크기는 보리 점·집 그림자와 섞인다.
3. **같은 ▲·✕ 다른 뜻:** 도술 갈래(부름 ▲·줄 ●·얼룩 ✕, 첫 도술 카드)와 처결(천도 ▲·파혼 ✕)이 같은 모양이다. 카드 틀 안/월드 안으로 자리가 달라 큰 문제는 아니지만 첫 10분에 둘 다 나온다. 헷갈린다는 QA가 나오면 도술 갈래 쪽 모양을 바꾸자.
4. **와이어프레임 ⑤ "오래된 주황":** 주황은 파혼 전용, 오래된 혼은 갈회색(#6E5446 근처)으로 정했으니 문구를 고쳐 주세요.
5. 기록 탭 줄 앞 표시(§9-2)는 16 px가 필요하다. 48²를 16 px로 줄이면 안쪽 하이라이트가 뭉개지므로, 필요하면 단순화판을 따로 만든다.
