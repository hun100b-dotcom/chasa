# 3막 아트 키트 계획 (기획 act3_map.json v1 기준, 아트 2026-10-25)

3막 = ⑤ 갯마을(x 768~1280, y 0~1024, 동쪽·바다) + ⑥ 도성 아랫마을(x -640~0, y 0~640, 서쪽) + 해안 길(y -128~0).
2막과 같은 순서로 간다: ①소품 키트 → ②땅(높이·색) → ③배치표·걷기 점검 → ④보스 모델.

## 2. 코드·아트 협의가 필요한 요구 (기획 노트)
1. **B-11 큰 다리 상판 반투명**: 다리 모델을 `bridge_deck`(상판·난간)과 `bridge_pier`(기둥·바닥)로 쪼갠다. 플레이어가 다리 밑 구역(BridgeUnder 사각형) 안에 들면 `bridge_deck`만 알파 0.25로 낮추거나 숨긴다. 재질은 알파 전환이 되도록 deck 전용 재질 한 개로 모은다. (코드팀이 사각형 트리거만 달면 됨)
2. **⑤ 장례 연기는 동쪽(바다 쪽)으로 흐름**: 연기 스프라이트의 이동 방향을 +x로 둔다. 연기 모양 자체는 아트가 방향 없는 구름으로 줄 수 있음 → 코드가 방향 파라미터를 받는다.
3. **썰물/밀물 물판**: 난파 여울·갯골은 물 높이가 25분 주기로 오르내림. 물판(`river_water.glb` 방식)을 여울용으로 하나 더 만들고, 코드가 높이를 움직인다. 바닥(갯벌)은 젖은 색이 항상 보이도록 땅 색 층 B(젖음)를 쓴다.
4. **땅 색 층(3막용)**: dirt=흙길, grass=갯풀, gravel=자갈·성벽 돌, paddy=소금 염전 흰색, leaf=눈·서리(⑥ 성문 밖), splat_b G=거품, B=젖은 갯벌.
5. 땅 크기: ⑤ 512×1024, ⑥ 640×640, 해안 띠. 2막 방식대로 origin 오프셋 Terrain을 구역별로 더 얹는 안이 가장 단순(코드팀 확인 필요).

## 3. 기획에게 물어볼 것
- ⑥ 성벽 안쪽 도성이 화면에 보이나(배경 그림이면 아트가 먼 경치 판으로 처리).
- 해안 길 벼랑 높이(1막 남쪽 벼랑과 같은 높이로 맞출지).

## 4. 순서 제안
포구·소금밭·곶 키트 → ⑤ 땅 → 큰 다리 분리 모델 → ⑥ 키트 → ⑥ 땅 → 배치표·걷기 → 보스 4종.
